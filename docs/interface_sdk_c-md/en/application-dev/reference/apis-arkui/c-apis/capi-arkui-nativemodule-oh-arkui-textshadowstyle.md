# OH_ArkUI_TextShadowStyle

```c
typedef struct OH_ArkUI_TextShadowStyle OH_ArkUI_TextShadowStyle
```

## Overview

Defines a text shadow style, which includes attributes such as the shadow offset, blur radius, and color. It is used to add shadow effects to text, such as highlighting title text and enhancing text on a dark background.<br> Call {@link OH_ArkUI_TextShadowStyle_Create} to create a text shadow style object.<br><br>Call {@link OH_ArkUI_TextShadowStyle_Destroy} to destroy the text shadow style object.<br><br>After creating the text shadow style object, call {@link OH_ArkUI_TextShadowStyle_SetTextShadow} to set the<br>specific text shadow style.<br><br>Call {@link OH_ArkUI_TextShadowStyle_GetTextShadow} to obtain the text shadow style that has been set.
