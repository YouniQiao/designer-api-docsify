typedef struct OH_ArkUI_NativeModule_UIJsonWrapper OH_ArkUI_NativeModule_UIJsonWrapper

## Overview

Defines an opaque, immutable JSON data object.<br> The object holds a JSON string. It is used both to carry data delivered by the framework (UI sensing) and to carry commands submitted by the application (UI control).

**System capability**: SystemCapability.ArkUI.ArkUI.Full
