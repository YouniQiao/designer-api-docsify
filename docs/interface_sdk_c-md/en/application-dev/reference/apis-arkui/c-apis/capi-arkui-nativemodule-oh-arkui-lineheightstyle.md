# OH_ArkUI_LineHeightStyle

```c
typedef struct OH_ArkUI_LineHeightStyle OH_ArkUI_LineHeightStyle
```

## Overview

Defines a line height style.<br> {@link OH_ArkUI_LineHeightStyle_Create} can be used to create a line height style object.<br><br>{@link OH_ArkUI_LineHeightStyle_Destroy} can be used to destroy the line height style object.<br><br>After the object is created, {@link OH_ArkUI_LineHeightStyle_SetLineHeight} can be used to set fixed line<br>height.<br><br>Since API version 26.0.0, {@link OH_ArkUI_LineHeightStyle_SetLineHeightMultiple} can be used to set the line height multiplier after the object is created.
