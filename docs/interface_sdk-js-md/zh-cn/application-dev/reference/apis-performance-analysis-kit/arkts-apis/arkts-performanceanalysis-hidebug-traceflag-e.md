# TraceFlag

描述采集trace线程的类型，包括主线程和所有线程。

**起始版本：** 12

**ArkTS模式：** ArkTS-Dyn起始版本为12；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.HiviewDFX.HiProfiler.HiDebug

## MAIN_THREAD

```TypeScript
MAIN_THREAD = 1
```

只采集当前应用主线程。

**起始版本：** 12

**ArkTS模式：** ArkTS-Dyn起始版本为12；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.HiviewDFX.HiProfiler.HiDebug

## ALL_THREADS

```TypeScript
ALL_THREADS = 2
```

采集当前应用下所有线程。

**起始版本：** 12

**ArkTS模式：** ArkTS-Dyn起始版本为12；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.HiviewDFX.HiProfiler.HiDebug
