# GetTextCallback

```TypeScript
export type GetTextCallback = (length: int) => string
```

获取编辑框最新状态下光标左侧指定长度的文本内容。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.MiscServices.InputMethodFramework

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| length | int | 是 |

**返回值：**

| 类型 |
| --- |
| string |
