# PublishFormErrorCode（系统接口）

Enumerates the result codes that may be used for the operation of adding a widget to the home screen.

**起始版本：** 12

**ArkTS模式：** ArkTS-Dyn起始版本为12；ArkTS-Sta起始版本为23。
