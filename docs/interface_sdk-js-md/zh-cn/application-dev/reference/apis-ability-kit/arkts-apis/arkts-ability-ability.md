# @ohos.ability.ability

Ability模块将二级模块API组织在一起方便开发者进行导出。

**起始版本：** 9

**模型约束：** 
- API版本9-10：此接口仅可在FA模型下使用。

**系统能力：** SystemCapability.Ability.AbilityRuntime.AbilityCore

## 导入模块

```TypeScript
import { ability } from 'kits/@kit.AbilityKit';
```
