# ToolInfo(CLI工具信息)

## 汇总

### 接口

| 名称 | 说明 |
| --- | --- |
| [SubCommandInfo](arkts-ability-toolinfo-subcommandinfo-i.md) | 描述CLI工具子命令的信息。 |
| [ToolInfo](arkts-ability-toolinfo-i.md) | ToolInfo用于描述系统命令行工具（CLI）的基本信息，包括工具名称、版本、描述、可执行路径、输入输出模式等。 |
| [ToolSummary](arkts-ability-toolinfo-toolsummary-i.md) | 描述CLI工具的摘要信息。 |
