# wantAgent

WantAgent模块提供了创建WantAgent实例、获取实例的用户ID、获取want信息、比较WantAgent实例和获取bundle名称等能力。

**起始版本：** 7

**废弃版本：** 9

**替代接口：** [wantAgent/wantAgent](arkts-ability-wantagent-n.md)
