# @ohos.app.ability.autoStartupManager

aautoStartupManager模块提供获取自身应用的开机自启状态以及检查设备是否支持开机自启动的能力。

**起始版本：** 21

**系统能力：** SystemCapability.Ability.AbilityRuntime.Core

## 导入模块

```TypeScript
import { autoStartupManager } from 'kits/@kit.AbilityKit';
```
