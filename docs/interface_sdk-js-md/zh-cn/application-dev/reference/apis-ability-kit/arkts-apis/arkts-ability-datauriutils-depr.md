# @ohos.ability.dataUriUtils(DataUriUtils模块)

DataUriUtils模块提供用于处理uri对象的能力，包括获取、绑定、删除和更新指定uri对象的路径末尾的ID。

**起始版本：** 7

**废弃版本：** 9

**替代接口：** [dataUriUtils/dataUriUtils](arkts-ability-app-ability-datauriutils.md)
