# ReminderLevel（系统接口）

Enumerates comfort reminder levels required for triggering specific alert ringtones.

**起始版本：** 26.0.0

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为26.0.0。
