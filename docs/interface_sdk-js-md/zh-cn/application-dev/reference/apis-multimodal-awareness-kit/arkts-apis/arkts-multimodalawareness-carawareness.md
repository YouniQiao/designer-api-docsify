# @ohos.multimodalAwareness.carAwareness

此模块提供使用汽车感知的功能

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.MultimodalAwareness.CarAwareness

## 导入模块

```TypeScript
import { carAwareness } from 'kits/@kit.MultimodalAwarenessKit';
```
