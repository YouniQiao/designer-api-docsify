# @ohos.stationary(设备状态感知框架)

设备状态感知框架提供设备状态感知能力，包括绝对静止和相对静止，适用于需要根据设备静止状态优化应用性能、智能省电、场景识别等场景。

> **说明：**&gt;
> 本模块不支持在x86平台上运行。

**起始版本：** 9

**系统能力：** SystemCapability.Msdp.DeviceStatus.Stationary

## 导入模块

```TypeScript
import { stationary } from 'kits/@kit.MultimodalAwarenessKit';
```
