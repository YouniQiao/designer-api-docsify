# Callback

Defines the window callback.

**起始版本：** 15

**系统能力：** SystemCapability.Window.SessionManager

## 导入模块

```TypeScript
import { window } from 'kits/@kit.ArkUI';
```

## [[Call]]

```TypeScript
(data: T): V
```

Defines the callback info.

**起始版本：** 15

**原子化服务API：** 从API版本15开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Window.SessionManager

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| data | T | 是 |

**返回值：**

| 类型 |
| --- |
| V |
