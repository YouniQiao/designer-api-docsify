# ImageAnalyzerType

图像AI分析类型，未设置时默认开启主体识别和文字识别功能。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** 
- API版本23+：SystemCapability.ArkUI.ArkUI.Full
