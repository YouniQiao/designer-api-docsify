# depthComponent

景深组件利用背景与深度图，生成具有景深空间效果的内容。
 > **说明：**
 >
 > - 子组件需要设置空间效果，才能与景深组件的背景产生交互效果。
 >
 > - 具备基本的计算机图形学知识有助于更好地使用该组件。
