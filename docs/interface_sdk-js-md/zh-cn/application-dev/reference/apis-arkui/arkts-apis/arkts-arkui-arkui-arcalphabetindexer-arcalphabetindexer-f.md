```TypeScript

    info: ArcAlphabetIndexerInitInfo
): ArcAlphabetIndexerAttribute
```

创建弧形索引条实例，传入弧形索引条配置项参数。无

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Circle
