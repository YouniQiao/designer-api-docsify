# ContentTransitionEffect

Defines the content transition effect.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## IDENTITY

```TypeScript
static get IDENTITY(): ContentTransitionEffect
```

When the content changes,there is no animation effect.@static

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## OPACITY

```TypeScript
static get OPACITY(): ContentTransitionEffect
```

When the content changes,there is a smooth fade-in and fade-out effect.@static

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
