# console

提供控制台。

**起始版本：** 3

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为3。

**系统能力：** SystemCapability.ArkUI.ArkUI.Lite

## debug

```TypeScript
static debug(message: string): void
```

打印调试信息。

**起始版本：** 3

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为3。

**模型约束：** 此接口仅可在FA模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Lite

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| message | string | 是 |
