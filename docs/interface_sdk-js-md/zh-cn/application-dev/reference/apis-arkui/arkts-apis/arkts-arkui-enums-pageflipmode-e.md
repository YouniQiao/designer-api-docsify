# PageFlipMode

Page flip mode of Swiper and Tabs on mouse wheel event.@enum { number } PageFlipMode

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## CONTINUOUS

```TypeScript
CONTINUOUS = 0
```

Turn pages continuously according to the number of mouse wheel events.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## SINGLE

```TypeScript
SINGLE = 1
```

The page-turning animation remains unresponsive to other mouse wheel events until it completes.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
