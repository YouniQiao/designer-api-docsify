# checkbox

提供多选框组件，通常用于某选项的打开或关闭。
 > **说明：**
 >
 > - 本模块同时支持ArkTS-Dyn、ArkTS-Sta。
 >
 > - API version 11开始，Checkbox默认样式由圆角方形变为圆形。
 >
 > - 该组件默认有margin间距，默认值为：{&nbsp;top: '14px',&nbsp;right: '14px',&nbsp;bottom: '14px',&
 > nbsp;left: '14px' }。
 ###### 子组件
 无
