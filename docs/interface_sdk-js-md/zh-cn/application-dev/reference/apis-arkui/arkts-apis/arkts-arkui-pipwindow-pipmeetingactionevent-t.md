# PiPMeetingActionEvent

```TypeScript
type PiPMeetingActionEvent = 'hangUp' | 'voiceStateChanged' | 'videoStateChanged' | 'micStateChanged'
```

视频会议控制事件类型。

**起始版本：** 11

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Window.SessionManager

| 类型 |
| --- |
| 'hangUp' |
| 'voiceStateChanged' |
| 'videoStateChanged' |
| 'micStateChanged' |
