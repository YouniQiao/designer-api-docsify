# ConstraintSizeOptions

约束尺寸类型，用于描述组件布局时对尺寸大小的范围限制。
    **说明：**  
    
    在[Row]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_、[Column]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_、  
    [RelativeContainer]\_\_\_JSDOC\_LINK\_DESC\_USD\_2\_\_\_组件中，width、height设置auto表示自适应子组件。在  
    [TextInput]\_\_\_JSDOC\_LINK\_DESC\_USD\_3\_\_\_组件中，width设置auto表示自适应文本宽度。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。
