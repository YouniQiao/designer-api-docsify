# TransitionControllerCallback（系统接口）

```TypeScript
declare type TransitionControllerCallback = (context: window.TransitionContext) => void
```

Callback function for transition controller

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.WindowManager.WindowManager.Core

**系统接口：** 此接口为系统接口。

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| context | [window.TransitionContext](arkts-arkui-window-transitioncontext-i-sys.md) | 是 |
