# EdgeColors

```TypeScript
declare type EdgeColors
```

边框颜色，用于描述组件边框四条边的颜色。

引入该对象时，至少传入一个参数。

**起始版本：** 9

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。

**卡片能力：** 从API版本9开始，该接口支持在ArkTS卡片中使用。
