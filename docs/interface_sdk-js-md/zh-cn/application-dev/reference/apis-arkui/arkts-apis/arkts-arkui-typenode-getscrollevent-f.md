```TypeScript
export function getScrollEvent(node: FrameNode): UIScrollEvent | undefined
```

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| node | [FrameNode](arkts-arkui-framenode-c.md) | 是 |

**返回值：**

| 类型 |
| --- |
| UIScrollEvent \| undefined |
