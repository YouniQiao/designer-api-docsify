# ProgressMask

Implements a ProgressMask object to set the progress, maximum value, and color of the mask.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
