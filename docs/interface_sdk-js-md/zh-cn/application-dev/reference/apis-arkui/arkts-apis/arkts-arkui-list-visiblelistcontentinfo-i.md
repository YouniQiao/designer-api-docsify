# VisibleListContentInfo

定义List可见内容区子组件的详细信息。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## index

```TypeScript
index: int
```

表示ListItem或ListItemGroup在List中的索引值。 取值限定为整数。

**类型：** int

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## itemGroupArea

```TypeScript
itemGroupArea?: ListItemGroupArea
```

表示处于ListItemGroup的哪一个区域。

**类型：** [ListItemGroupArea](arkts-arkui-list-listitemgrouparea-e.md)

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## itemIndexInGroup

```TypeScript
itemIndexInGroup?: int
```

表示ListItem在ListItemGroup中的索引值。 取值限定为整数。

**类型：** int

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
