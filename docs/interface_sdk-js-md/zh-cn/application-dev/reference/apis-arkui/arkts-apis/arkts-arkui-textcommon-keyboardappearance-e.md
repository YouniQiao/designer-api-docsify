# KeyboardAppearance

键盘外观。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## NONE_IMMERSIVE

```TypeScript
NONE_IMMERSIVE = 0
```

默认外观模式，不采用沉浸式风格。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## IMMERSIVE

IMMERSIVE = 1
