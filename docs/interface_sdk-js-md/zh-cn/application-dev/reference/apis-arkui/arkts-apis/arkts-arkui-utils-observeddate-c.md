# ObservedDate

继承自Date，为可观察API操作的Date对象。详见 ObservedArray/ObservedMap/ObservedSet/ObservedDate：具有观察能力的Built-in类型。

**继承/实现关系：** ObservedDate extends [Date](../../apis-arkts/arkts-apis/arkts-arkts-date-c.md)

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为26.0.0。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
