# menuItemGroup

该组件用来展示菜单MenuItem的分组。
 > **说明：**
 >
 > - 本模块同时支持ArkTS-Dyn、ArkTS-Sta。
 > - 该组件从API版本26.0.0开始支持[WithTheme](with_theme)。
 ###### 子组件
 包含[MenuItem](menu_item)子组件。
