# OnMoveHandler

```TypeScript
export type OnMoveHandler = (from: int, to: int) => void
```

Defines the onMove callback.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| from | int | 是 |
| to | int | 是 |
