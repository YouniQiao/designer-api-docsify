## compatibleWrappedBuilder

```TypeScript
export declare function compatibleWrappedBuilder(builder: Any, ...args: FixedArray<ESValue>): void
```

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| builder | Any | 是 |
| [args](../../apis-arkdata/arkts-apis/arkts-arkdata-relationalstore-sqlinfo-i.md) | FixedArray & lt;ESValue & gt; | 是 |
