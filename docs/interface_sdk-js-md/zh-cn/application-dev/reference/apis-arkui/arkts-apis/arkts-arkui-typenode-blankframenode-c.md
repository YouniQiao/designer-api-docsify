# BlankFrameNode

定义Blank类型的FrameNode。

**继承/实现关系：** BlankFrameNode extends TypedFrameNode<BlankAttribute>

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
