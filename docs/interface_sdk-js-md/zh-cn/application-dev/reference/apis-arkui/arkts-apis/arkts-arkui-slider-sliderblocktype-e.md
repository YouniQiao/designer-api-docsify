# SliderBlockType

Slider组件滑块形状枚举。  
| 名称 | 值 | 说明 | | ------- | -- | ---------------------- | | [DEFAULT](#default) | 0 | 使用默认滑块（圆形）。 | | [IMAGE](#image) | 1 | 使用图片资源作为滑块。 | | [SHAPE](#shape) | 2 |

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
