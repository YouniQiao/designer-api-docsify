# SpecificSystemBar

```TypeScript
type SpecificSystemBar = 'status' | 'navigation'| 'navigationIndicator'
```

当前支持显示或隐藏的系统栏类型。

**起始版本：** 11

**ArkTS模式：** ArkTS-Dyn起始版本为11；ArkTS-Sta起始版本为23。

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Window.SessionManager

| 类型 |
| --- |
| 'status' |
| 'navigation' |
| 'navigationIndicator' |
