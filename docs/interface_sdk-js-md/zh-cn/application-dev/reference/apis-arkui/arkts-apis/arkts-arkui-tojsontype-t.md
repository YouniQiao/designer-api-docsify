# ToJSONType

```TypeScript
export declare type ToJSONType<T> = (value: T) => jsonx.JsonElement
```


> **说明：**&gt;
> 静态ArkTS序列化接口，需开发者自己实现。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| value | T | 是 |

**返回值：**

| 类型 |
| --- |
| jsonx.JsonElement |
