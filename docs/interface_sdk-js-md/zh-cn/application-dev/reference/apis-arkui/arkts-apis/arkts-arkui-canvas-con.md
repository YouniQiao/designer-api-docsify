# 常量

## Canvas

```TypeScript
declare const Canvas: CanvasInterface
```

提供画布组件，用于自定义绘制图形。

## 子组件

不支持。

**起始版本：** 8

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**卡片能力：** 从API版本9开始，该接口支持在ArkTS卡片中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

declare const CanvasInstance: CanvasAttribute
