# component/radio

单选框，提供相应的用户交互选择项。
 > **说明：**
 >
 > - 本模块同时支持ArkTS-Dyn、ArkTS-Sta。
 >
 > - API version 12开始，Radio选中默认样式由RadioIndicatorType.DOT变为RadioIndicatorType.TICK。
 >
 > -
 >
 > - 该组件默认有[margin](../arkts-arkui-component/common-commonmethod-i.md#margin)间距，默认值为：{&nbsp;top: '14px',&nbsp;right: '14px',&nbsp;bottom: '14px',&
 > nbsp;left: '14px' }。
 ###### 子组件
 无
