# Area

区域类型，用于存储元素所占的区域信息。@interface Area

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## globalPosition

```TypeScript
globalPosition: Position
```

目标元素左上角在当前窗口坐标系中的位置。

**类型：** [Position](arkts-arkui-units-position-i.md)

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
