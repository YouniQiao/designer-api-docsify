# SceneOptions

3D场景控制使用的场景选项@interface SceneOptions

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.ArkUi.Graphics3D

## modelType

```TypeScript
modelType?: ModelType
```

3D渲染时的场景类型

**类型：** [ModelType](arkts-arkui-component3d-modeltype-e.md)

**默认值：** ModelType.SURFACE 表面模型类型

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.ArkUi.Graphics3D

## scene

```TypeScript
scene?: ResourceStr | Scene
```

3D渲染时为ResourceStr类型，3D场景控制时为Scene类型

**类型：** [ResourceStr](arkts-arkui-resourcestr-t.md) \| Scene

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.ArkUi.Graphics3D
