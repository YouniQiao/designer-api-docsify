# CalendarPicker

## CalendarPicker

```TypeScript
export declare function CalendarPicker(
    options?: CalendarOptions
): CalendarPickerAttribute
```

定义日历选择器组件。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| options | [CalendarOptions](arkts-arkui-calendarpicker-calendaroptions-i.md) | 否 |

**返回值：**

| 类型 |
| --- |
| [CalendarPickerAttribute](arkts-arkui-calendarpicker-calendarpickerattribute-i.md) |
