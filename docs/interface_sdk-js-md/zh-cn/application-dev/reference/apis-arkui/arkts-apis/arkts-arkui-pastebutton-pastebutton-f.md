# PasteButton

## PasteButton

```TypeScript
export declare function PasteButton(
    options?: PasteButtonOptions
): PasteButtonAttribute
```

Set a paste button.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
