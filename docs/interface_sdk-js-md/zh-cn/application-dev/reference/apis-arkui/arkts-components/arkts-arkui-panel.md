# Panel

可滑动面板，提供一种轻量的内容展示窗口，方便在不同尺寸中切换。

## Panel

```TypeScript
Panel(show: boolean)
```

滑动面板组件。

**起始版本：** 7

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为7。

**废弃版本：** 12

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**参数:**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| show | boolean | 是 |
