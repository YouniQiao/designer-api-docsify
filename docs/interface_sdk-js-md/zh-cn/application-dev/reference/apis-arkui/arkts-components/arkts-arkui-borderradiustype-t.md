# BorderRadiusType

```TypeScript
type BorderRadiusType = Length | BorderRadiuses | LocalizedBorderRadiuses
```

**起始版本：** 19

**原子化服务API：** 从API版本19开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
