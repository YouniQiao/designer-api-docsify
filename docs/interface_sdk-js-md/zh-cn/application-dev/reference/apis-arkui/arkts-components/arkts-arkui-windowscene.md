# WindowScene

Defines the WindowScene component.

## WindowScene

```TypeScript
WindowScene(persistentId: number)
```

Called when the WindowScene is used.

**起始版本：** 10

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为10。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**系统接口：** 此接口为系统接口。

**参数:**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| persistentId | number | 是 | indicates the persistent identifier of WindowScene. |
