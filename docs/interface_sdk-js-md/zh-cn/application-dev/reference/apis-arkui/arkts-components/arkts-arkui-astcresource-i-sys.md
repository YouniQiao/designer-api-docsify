# ASTCResource（系统接口）

Defines the resource which can use ASTC.

**起始版本：** 12

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为12。

<!--Device-unnamed-interface ASTCResource--><!--Device-unnamed-interface ASTCResource-End-->

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**系统接口：** 此接口为系统接口。

## column

```TypeScript
column: number
```

Column size, indicating the number of ASTC resources to splice per row.

**类型：** number

**起始版本：** 12

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为12。

**模型约束：** 此接口仅可在Stage模型下使用。

## sources

```TypeScript
sources: Array<string>
```

Array of ASTC uri resources, indicating the range of ASTC data to be obtained.

**类型：** Array&lt;string&gt;

**起始版本：** 12

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为12。

**模型约束：** 此接口仅可在Stage模型下使用。
