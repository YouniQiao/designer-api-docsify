# RootScene

Defines the RootScene component.

## RootScene

```TypeScript
RootScene(session: RootSceneSession)
```

Called when the RootScene is used.

**起始版本：** 10

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为10。

**模型约束：** 此接口仅可在Stage模型下使用。
