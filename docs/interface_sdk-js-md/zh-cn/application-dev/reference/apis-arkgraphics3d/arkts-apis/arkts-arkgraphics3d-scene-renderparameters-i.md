## alwaysRender

```TypeScript
alwaysRender?: boolean
```

表示是否每一帧都渲染。true表示每一帧都渲染，false表示按需渲染。默认值为true。

**类型：** boolean

**起始版本：** 15

**ArkTS模式：** ArkTS-Dyn起始版本为15；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.ArkUi.Graphics3D
