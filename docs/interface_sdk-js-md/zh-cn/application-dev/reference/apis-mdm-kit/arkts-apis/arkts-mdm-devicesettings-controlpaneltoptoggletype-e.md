# ControlPanelTopToggleType

```TypeScript
enum ControlPanelTopToggleType
```

控制中心1×2区域可裁剪开关项枚举。不同设备支持的开关项可能不同；不支持的开关项设置后不生效，控制中心不会显示对应图标。

**起始版本：** 26.1.0
