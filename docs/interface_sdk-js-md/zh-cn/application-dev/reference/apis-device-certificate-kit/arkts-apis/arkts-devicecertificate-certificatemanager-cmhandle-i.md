# CMHandle

表示签名、验签的初始化操作句柄。

**起始版本：** 11

**ArkTS模式：** ArkTS-Dyn起始版本为11；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Security.CertificateManager

## 导入模块

```TypeScript
import { certificateManager } from '@kit.DeviceCertificateKit';
```

## handle

```TypeScript
handle: Uint8Array
```

签名、验签的初始化操作句柄，最大长度为8字节。

**类型：** Uint8Array

**起始版本：** 11

**ArkTS模式：** ArkTS-Dyn起始版本为11；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Security.CertificateManager
