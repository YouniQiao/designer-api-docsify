## toString

```TypeScript
export function toString(self: FixedArray<boolean>): string
```

返回表示指定数组及其元素的字符串。

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| self | FixedArray & lt;boolean & gt; | 是 |

**返回值：**

| 类型 |
| --- |
| string |
