# transferDynamic

## 导入模块

```TypeScript
import { transfer } from '@kit.ArkTS';
```

## transferDynamic

```TypeScript
function transferDynamic(input: Object, inputName: string): Any
```

将1.2对象转换为1.0对象。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**原子化服务API：** 从API版本23开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| input | Object | 是 |
| inputName | string | 是 |

**返回值：**

| 类型 |
| --- |
| Any |

**错误码：**

| 错误码ID |
| --- |
| 10200067 |
