# join

## join

```TypeScript
export function join(self: FixedArray<boolean>, sep?: string): string
```

Creates and returns a new string by concatenating all of the elements in an `Array`, separated by a specified separator string.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function join(self: FixedArray<boolean>, sep?: string): string--><!--Device-unnamed-export function join(self: FixedArray<boolean>, sep?: string): string-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | 是 | The array to operate `join` on. |
| sep | string | 否 | A string to separate each pair of adjacent elements of the array. If omitted, the array elements are separated with a comma. |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| string | A string with all array elements joined. |
