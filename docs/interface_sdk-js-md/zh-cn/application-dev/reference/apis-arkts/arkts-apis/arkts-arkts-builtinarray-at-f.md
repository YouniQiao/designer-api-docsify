# at

## at

```TypeScript
export function at(self: FixedArray<boolean>, index: int): Boolean
```

Takes an integer value and returns the item at that index, allowing for positive and negative integers. Negative integers count back from the last item in the array.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function at(self: FixedArray<boolean>, index: int): Boolean--><!--Device-unnamed-export function at(self: FixedArray<boolean>, index: int): Boolean-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | 是 | The array to operate `at` on. |
| index | int | 是 | Zero-based index of the array element to be returned. &lt;br&gt;The value should be an integer. |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| Boolean | The element at the given index. |
