# sort

## sort

```TypeScript
export function sort(self: FixedArray<boolean>, comparator: (a: boolean, b: boolean) => int, start?: int, end?: int): 
    FixedArray<boolean>
```

Reorders elements of this array using comparator function.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function sort(self: FixedArray<boolean>, comparator: (a: boolean, b: boolean) => int, start?: int, end?: int):     FixedArray<boolean>--><!--Device-unnamed-export function sort(self: FixedArray<boolean>, comparator: (a: boolean, b: boolean) => int, start?: int, end?: int):     FixedArray<boolean>-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | 是 | The array to operate `sort` on. |
| comparator | (a: boolean, b: boolean) =&gt; int | 是 | A function that defines the sort order. |
| start | int | 否 | The start index to sort from. &lt;br&gt;The value should be an integer. |
| end | int | 否 | The end index to sort to. &lt;br&gt;The value should be an integer. |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| FixedArray&lt;boolean&gt; | The sorted array. |
