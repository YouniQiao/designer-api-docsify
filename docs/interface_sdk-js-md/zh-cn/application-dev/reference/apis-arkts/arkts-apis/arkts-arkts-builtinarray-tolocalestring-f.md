# toLocaleString

## toLocaleString

```TypeScript
export function toLocaleString(self: FixedArray<boolean>, locales: Object, options: Object): string
```

Returns a string representing the elements of the array. The elements are converted to Strings using their toLocaleString methods.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function toLocaleString(self: FixedArray<boolean>, locales: Object, options: Object): string--><!--Device-unnamed-export function toLocaleString(self: FixedArray<boolean>, locales: Object, options: Object): string-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | 是 | The array to operate `toLocaleString` on. |
| locales | Object | 是 | A string with a BCP 47 language tag, or an array of such strings. |
| options | Object | 是 | An object with configuration properties. |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| string | A string representing the elements of the array. |
