# chdir（系统接口）

## 导入模块

```TypeScript
import { process } from '@kit.ArkTS';
```

## chdir

```TypeScript
function chdir(dir: string): void
```

修改当前目录。

**起始版本：** 7

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为7。

**系统能力：** SystemCapability.Utils.Lang

**系统接口：** 此接口为系统接口。

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| dir | string | 是 |
