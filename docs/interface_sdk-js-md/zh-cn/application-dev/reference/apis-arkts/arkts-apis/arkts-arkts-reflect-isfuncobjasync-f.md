## isFuncObjAsync

```TypeScript
export function isFuncObjAsync(target: Function): boolean
```

判断函数对象是否由async函数降级生成。

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| target | Function | 是 |

**返回值：**

| 类型 |
| --- |
| boolean |
