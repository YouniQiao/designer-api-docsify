# ScopeType

```TypeScript
type ScopeType = ScopeComparable | number
```

定义 **Scope** 对象中的值类型。

**起始版本：** 8

**ArkTS模式：** ArkTS-Dyn起始版本为8；ArkTS-Sta起始版本为23。

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Utils.Lang
