## includes

```TypeScript
export function includes(self: FixedArray<boolean>, val: boolean, fromIndex?: int): boolean
```

判断数组的元素中是否包含指定的值，并相应地返回true或false。

**起始版本：** 26.0.0

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function includes(self: FixedArray<boolean>, val: boolean, fromIndex?: int): boolean--><!--Device-unnamed-export function includes(self: FixedArray<boolean>, val: boolean, fromIndex?: int): boolean-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | 是 | 执行`includes`操作的数组。 |
| val | boolean | 是 | 待查找的值。 |
| fromIndex | int | 否 | 在该数组中开始查找value的位置。 <br>取值约束：应为整数。 |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| boolean | 如果找到该值则返回true，否则返回false。 |
