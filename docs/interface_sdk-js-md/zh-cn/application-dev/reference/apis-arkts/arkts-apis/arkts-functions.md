| [decodeURIComponent](arkts-arkts-functions-decodeuricomponent-f.md) | decodeURIComponent()函数用于解码由 encodeURIComponent()或类似方法创建的 统一资源标识符（URI）组成部分。 |
| [encodeURI](arkts-arkts-functions-encodeuri-f.md) | encodeURI()函数对URI进行编码， 将其中的某些字符各自替换为一个、两个、三个或四个转义序列， 这些转义序列表示该字符的UTF-8编码（仅当字符由两个 代理项字符组成时，才会是四个转义 序列）。与encodeURIComponent()相比，该函数 编码的字符更少，会保留属于 URI语法组成部分的字符。 |
| [encodeURIComponent](arkts-arkts-functions-encodeuricomponent-f.md) | encodeURIComponent()函数对URI进行编码， 将其中的某些字符各自替换为一个、两个、三个或四个 转义序列，这些转义序列表示该字符的UTF-8编码 （仅当字符由两个代理项字符组成时，才会是 四个转义序列）。与encodeURI()相比，该函数 编码的字符更多，包括属于URI语法 组成部分的字符。 |
