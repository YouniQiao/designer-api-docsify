# JsonType

JSON值可能类型的枚举。 用于在运行时识别JsonElement的类型。

**起始版本：** 26.0.0

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为26.0.0。
