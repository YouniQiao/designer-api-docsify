# slice

## slice

```TypeScript
export function slice(self: FixedArray<boolean>, start: int): FixedArray<boolean>
```

Returns a copy of a section of an array.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function slice(self: FixedArray<boolean>, start: int): FixedArray<boolean>--><!--Device-unnamed-export function slice(self: FixedArray<boolean>, start: int): FixedArray<boolean>-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | 是 | The array to operate `slice` on. |
| start | int | 是 | The beginning index of the specified portion of the array. &lt;br&gt;The value should be an integer. |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| FixedArray&lt;boolean&gt; | A new Array object containing the extracted elements. |
