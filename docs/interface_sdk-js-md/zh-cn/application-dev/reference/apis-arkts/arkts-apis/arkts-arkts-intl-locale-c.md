**继承/实现关系：** Locale implements [LocaleOptions](arkts-arkts-intl-localeoptions-i.md)

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为26.0.0。

**系统能力：** SystemCapability.Utils.Lang
