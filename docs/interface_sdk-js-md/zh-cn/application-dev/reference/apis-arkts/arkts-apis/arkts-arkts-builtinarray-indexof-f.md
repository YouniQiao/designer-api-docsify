# indexOf

## indexOf

```TypeScript
export function indexOf(self: FixedArray<boolean>, val: boolean, fromIndex?: int): int
```

Returns the first index at which a given element can be found in the array, or -1 if it is not present.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function indexOf(self: FixedArray<boolean>, val: boolean, fromIndex?: int): int--><!--Device-unnamed-export function indexOf(self: FixedArray<boolean>, val: boolean, fromIndex?: int): int-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | 是 | The array to operate `indexOf` on. |
| val | boolean | 是 | The element to locate in the array. |
| fromIndex | int | 否 | The index to start in the array. &lt;br&gt;The value should be an integer. |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| int | The first index of the element in the array; -1 if not found. |
