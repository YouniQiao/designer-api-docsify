## copyWithin

```TypeScript
export function copyWithin(self: FixedArray<boolean>, target: int): FixedArray<boolean>
```

将数组的一部分浅拷贝到同一数组的其他位置并返回该数组， 且不改变其长度。

**起始版本：** 26.0.0

**ArkTS模式：** ArkTS-Sta起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。
