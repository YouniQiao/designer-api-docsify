# sort_subarray

## sort_subarray

```TypeScript
export function sort_subarray(arr: FixedArray<boolean>, startIndex: int, endIndex: int,
    mustPrecede: (lhs: boolean, rhs: boolean) => boolean): void
```

Sorts the array in-place.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

**参数：**

```TypeScript
export function sort_subarray(arr: FixedArray<char>, startIndex: int, endIndex: int,
    mustPrecede: (lhs: char, rhs: char) => boolean): void
```

Sorts the array in-place.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| arr | FixedArray&lt;char&gt; | 是 | The array to sort. |
| startIndex | int | 是 | The index to start sorting with, inclusive. &lt;br&gt;The value should be an integer. |
| endIndex | int | 是 | The index to end sorting, exclusive. &lt;br&gt;The value should be an integer. |
| mustPrecede | (lhs: char, rhs: char) =&gt; boolean | 是 | The must precede function. |
