# @arkts.lang

本模块提供ArkTS语言的基础类型定义，支持跨线程传递数据结构、注解保留策略控制等功能。当前提供ISendable类型、RetentionPolicy枚举类型和Retention注解。

## 导入模块

```TypeScript
import { lang, Retention, RetentionPolicy } from '@kit.ArkTS';
```
