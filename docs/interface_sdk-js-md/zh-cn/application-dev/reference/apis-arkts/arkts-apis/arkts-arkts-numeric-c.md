# Numeric

Can be implemented by any type that represents a numeric value

**继承/实现关系：** Numeric extends [Object](arkts-arkts-object-c.md)

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

## toByte

```TypeScript
public abstract toByte(): byte
```
