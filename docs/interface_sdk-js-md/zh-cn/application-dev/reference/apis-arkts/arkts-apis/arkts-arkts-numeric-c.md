# Numeric

可由任何表示数值的类型实现。

**继承/实现关系：** Numeric extends [Object](arkts-arkts-object-c.md)

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为26.0.0。

**系统能力：** SystemCapability.Utils.Lang

