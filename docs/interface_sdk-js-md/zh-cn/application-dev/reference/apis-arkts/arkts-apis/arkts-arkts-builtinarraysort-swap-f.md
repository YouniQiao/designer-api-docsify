## swap

```TypeScript
export function swap(arr: FixedArray<boolean>, i: int, j: int): void
```

交换数组中的两个元素。

**起始版本：** 26.0.0

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function swap(arr: FixedArray<boolean>, i: int, j: int): void--><!--Device-unnamed-export function swap(arr: FixedArray<boolean>, i: int, j: int): void-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| arr | FixedArray&lt;boolean&gt; | 是 | 待交换元素的数组。 |
| i | int | 是 | 待交换的第一个元素的索引。 <br>取值约束：应为整数。 |
| j | int | 是 | 待交换的第二个元素的索引。 <br>取值约束：应为整数。 |
