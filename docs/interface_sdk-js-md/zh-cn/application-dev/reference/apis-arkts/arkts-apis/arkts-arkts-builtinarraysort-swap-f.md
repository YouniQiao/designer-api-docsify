# swap

## swap

```TypeScript
export function swap(arr: FixedArray<boolean>, i: int, j: int): void
```

Swaps two elements in the array.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function swap(arr: FixedArray<boolean>, i: int, j: int): void--><!--Device-unnamed-export function swap(arr: FixedArray<boolean>, i: int, j: int): void-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| arr | FixedArray&lt;boolean&gt; | 是 | The array to swap elements in. |
| i | int | 是 | The index of the first element to swap. &lt;br&gt;The value should be an integer. |
| j | int | 是 | The index of the second element to swap. &lt;br&gt;The value should be an integer. |
