## swap

```TypeScript
export function swap(arr: FixedArray<boolean>, i: int, j: int): void
```

交换数组中的两个元素。

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| arr | FixedArray & lt;boolean & gt; | 是 |
| i | int | 是 |
| j | int | 是 |
