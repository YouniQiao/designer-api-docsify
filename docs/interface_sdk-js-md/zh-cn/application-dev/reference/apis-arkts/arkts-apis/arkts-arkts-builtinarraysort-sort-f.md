# sort

## sort

```TypeScript
export function sort(arr: FixedArray<boolean>, startIndex: int, endIndex: int): void
```

Sorts the array in-place.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function sort(arr: FixedArray<boolean>, startIndex: int, endIndex: int): void--><!--Device-unnamed-export function sort(arr: FixedArray<boolean>, startIndex: int, endIndex: int): void-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| arr | FixedArray&lt;boolean&gt; | 是 | The array to sort. |
| startIndex | int | 是 | The index to start sorting with, inclusive. &lt;br&gt;The value should be an integer. |
| endIndex | int | 是 | The index to end sorting, exclusive. &lt;br&gt;The value should be an integer. |
