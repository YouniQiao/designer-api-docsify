# copyTo

## copyTo

```TypeScript
export function copyTo(src: FixedArray<boolean>, dst: FixedArray<boolean>, dstStart: int, srcStart: int, srcEnd: int)
    : void
```

Copies src array into dst with respect to passed indexes.dst must have enough space, otherwise out-of-bounds might occur

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function copyTo(src: FixedArray<boolean>, dst: FixedArray<boolean>, dstStart: int, srcStart: int, srcEnd: int)    : void--><!--Device-unnamed-export function copyTo(src: FixedArray<boolean>, dst: FixedArray<boolean>, dstStart: int, srcStart: int, srcEnd: int)    : void-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| src | FixedArray&lt;boolean&gt; | 是 | The array to copy from |
| dst | FixedArray&lt;boolean&gt; | 是 | The array to copy into |
| dstStart | int | 是 | The index of dst to start from &lt;br&gt;The value should be an integer. |
| srcStart | int | 是 | The index of src to start from &lt;br&gt;The value should be an integer. |
| srcEnd | int | 是 | The last index of src to copy, exclusive, i.e. src[srcEnd] is not copied &lt;br&gt;The value should be an integer. |
