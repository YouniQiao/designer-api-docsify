# toSorted

## toSorted

```TypeScript
export function toSorted(self: FixedArray<boolean>): FixedArray<boolean>
```

Returns a new array with the elements sorted in ascending order.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function toSorted(self: FixedArray<boolean>): FixedArray<boolean>--><!--Device-unnamed-export function toSorted(self: FixedArray<boolean>): FixedArray<boolean>-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | 是 | The array to operate `toSorted` on. |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| FixedArray&lt;boolean&gt; | A new sorted array. |
