## lastIndexOf

```TypeScript
export function lastIndexOf(self: FixedArray<boolean>, element: boolean, fromIndex?: int): int
```

返回指定元素在数组中最后一次出现的索引，若不存在则返回-1。 查找按逆序进行。

**起始版本：** 26.0.0

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | 是 | 执行`lastIndexOf`操作的数组。 |
| element | boolean | 是 |  |
| fromIndex | int | 否 | 在数组中开始查找的索引。 <br>取值约束：应为整数。 |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| int | 该元素在数组中最后一次出现的索引，未找到时返回-1。 |
