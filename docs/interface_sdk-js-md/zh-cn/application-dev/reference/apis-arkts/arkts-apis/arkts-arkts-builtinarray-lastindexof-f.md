# lastIndexOf

## lastIndexOf

```TypeScript
export function lastIndexOf(self: FixedArray<boolean>, element: boolean, fromIndex?: int): int
```

Returns the last index at which a given element can be found in the array, or -1 if it is not present. The array is searched backwards.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function lastIndexOf(self: FixedArray<boolean>, element: boolean, fromIndex?: int): int--><!--Device-unnamed-export function lastIndexOf(self: FixedArray<boolean>, element: boolean, fromIndex?: int): int-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | 是 | The array to operate `lastIndexOf` on. |
| element | boolean | 是 |  |
| fromIndex | int | 否 | The index to start in the array. &lt;br&gt;The value should be an integer. |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| int | The last index of the element in the array; -1 if not found. |
