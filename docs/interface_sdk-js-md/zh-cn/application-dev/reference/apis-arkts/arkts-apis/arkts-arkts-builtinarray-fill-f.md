## fill

```TypeScript
export function fill(self: FixedArray<boolean>, value: boolean, start?: int, end?: int): FixedArray<boolean>
```

将数组中从起始索引到结束索引之间的所有元素替换为固定值。

**起始版本：** 26.0.0

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function fill(self: FixedArray<boolean>, value: boolean, start?: int, end?: int): FixedArray<boolean>--><!--Device-unnamed-export function fill(self: FixedArray<boolean>, value: boolean, start?: int, end?: int): FixedArray<boolean>-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | 是 | 执行`fill`操作的数组。 |
| value | boolean | 是 | 用于填充数组的值。 |
| start | int | 否 | 开始填充的索引（可选）。 <br>取值约束：应为整数。 |
| end | int | 否 | 结束填充的索引（可选，不包含）。 <br>取值约束：应为整数。 |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| FixedArray&lt;boolean&gt; | 修改后的数组。 |
