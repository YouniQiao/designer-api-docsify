# fill

## fill

```TypeScript
export function fill(self: FixedArray<boolean>, value: boolean, start?: int, end?: int): FixedArray<boolean>
```

Changes all elements in the Array to a static value, from a start index to an end index.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-unnamed-export function fill(self: FixedArray<boolean>, value: boolean, start?: int, end?: int): FixedArray<boolean>--><!--Device-unnamed-export function fill(self: FixedArray<boolean>, value: boolean, start?: int, end?: int): FixedArray<boolean>-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | 是 | The array to operate `fill` on. |
| value | boolean | 是 | The value to fill the array with. |
| start | int | 否 | The index at which to start filling (optional). &lt;br&gt;The value should be an integer. |
| end | int | 否 | The index at which to end filling (optional, not included). &lt;br&gt;The value should be an integer. |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| FixedArray&lt;boolean&gt; | The modified array. |
