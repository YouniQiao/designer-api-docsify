```TypeScript
type EllipticalMaskCenter = [
  double,
```

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Multimedia.Image.Core

**系统接口：** 此接口为系统接口。

**属性类型：** ArkTS-Dyn: [
  number,
  number
]  <br>ArkTS-Sta：[
  double,
  double
]
