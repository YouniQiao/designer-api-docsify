# SensorFrequency

```TypeScript
type SensorFrequency = 'game' | 'ui' | 'normal'
```

传感器上报频率模式，提供预定义的频率档位，方便开发者快速设置常用的上报频率。

**起始版本：** 11

**ArkTS模式：** ArkTS-Dyn起始版本为11；ArkTS-Sta起始版本为23。

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Sensors.Sensor

| 类型 |
| --- |
| 'game' |
| 'ui' |
| 'normal' |
