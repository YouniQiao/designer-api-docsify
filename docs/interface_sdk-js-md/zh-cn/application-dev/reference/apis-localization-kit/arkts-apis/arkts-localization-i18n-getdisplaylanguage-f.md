## getDisplayLanguage

```TypeScript
export function getDisplayLanguage(language: string, locale: string, sentenceCase?: boolean): string
```

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| language | string | 是 |
| locale | string | 是 |
| sentenceCase | boolean | 否 |

**返回值：**

| 类型 |
| --- |
| string |
