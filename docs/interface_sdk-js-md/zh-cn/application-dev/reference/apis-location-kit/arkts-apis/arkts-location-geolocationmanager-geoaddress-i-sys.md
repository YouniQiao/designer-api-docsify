# GeoAddress

地理编码地址信息。

**起始版本：** 9

**ArkTS模式：** ArkTS-Dyn起始版本为9；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Location.Location.Geocoder

## 导入模块

```TypeScript
import { geoLocationManager } from '@kit.LocationKit';
```

## isFromMock

```TypeScript
isFromMock?: Boolean
```

表示地名信息是否来自于逆地理编码模拟功能。 true：地名信息来自于逆地理编码模拟功能。 false：地名信息不是来自于逆地理编码模拟功能。

**类型：** Boolean

**起始版本：** 9

**ArkTS模式：** ArkTS-Dyn起始版本为9；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Location.Location.Geocoder

**系统接口：** 此接口为系统接口。
