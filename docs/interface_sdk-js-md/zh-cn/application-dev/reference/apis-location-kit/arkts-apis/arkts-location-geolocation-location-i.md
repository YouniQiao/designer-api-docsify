# Location

Provides information about geographic locations

**起始版本：** 7

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为7。

**废弃版本：** 9

**替代接口：** ohos.geoLocationManager/geoLocationManager.Location

**需要权限：** ohos.permission.LOCATION
