# BluetoothTransport

```TypeScript
type BluetoothTransport = connection.BluetoothTransport
```

Indicate the transport of a remote device.

**起始版本：** 26.0.0

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本26.0.0开始，该接口支持在原子化服务API中使用。
