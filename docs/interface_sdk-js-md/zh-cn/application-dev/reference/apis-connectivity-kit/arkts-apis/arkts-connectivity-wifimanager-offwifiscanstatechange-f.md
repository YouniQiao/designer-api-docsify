# offWifiScanStateChange

## 导入模块

```TypeScript
import { wifiManager } from '@kit.ConnectivityKit';
```

## offWifiScanStateChange

```TypeScript
function offWifiScanStateChange(callback?: Callback<int>): void
```

取消注册扫描状态改变事件。 如果未指定callback参数，将取消注册该事件关联的所有回调函数。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**需要权限：** ohos.permission.GET_WIFI_INFO

**系统能力：** SystemCapability.Communication.WiFi.STA

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| callback | [Callback](../../apis-basic-services-kit/arkts-apis/arkts-basicservices-base-callback-i.md)&lt;int&gt; | 否 |

**错误码：**

| 错误码ID |
| --- |
| [201](../../errorcode-universal.md#201-权限校验失败) |
| [801](../../errorcode-universal.md#801-该设备不支持此api) |
| [2501000](../errorcode-wifi.md#2501000-sta内部异常) |
