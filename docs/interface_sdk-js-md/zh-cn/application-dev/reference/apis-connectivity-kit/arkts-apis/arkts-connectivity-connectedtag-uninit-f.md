UnInitializes Connected Tag.

**起始版本：** 8

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为8。

**废弃版本：** 9

**替代接口：** ohos.connectedTag/connectedTag#uninitialize

**需要权限：** ohos.permission.NFC_TAG
