# MajorMinorClass

```TypeScript
type MajorMinorClass = constant.MajorMinorClass
```

Indicate the major minor class of a bluetooth device.

**起始版本：** 10

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
