# @ohos.connectedTag(有源标签)

本模块提供有源标签的使用，包括初始化有源标签芯片、读取有源标签内容、写入内容到有源标签等。

**起始版本：** 8

**系统能力：** SystemCapability.Communication.ConnectedTag

## 导入模块

```TypeScript
import { connectedTag } from 'kits/@kit.ConnectivityKit';
```
