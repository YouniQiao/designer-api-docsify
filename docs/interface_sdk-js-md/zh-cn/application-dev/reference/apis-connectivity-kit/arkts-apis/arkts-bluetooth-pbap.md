# @ohos.bluetooth.pbap

Provides methods to accessing bluetooth PBAP(Phone Book Access Profile)-related capabilities.

**起始版本：** 11

**ArkTS模式：** ArkTS-Dyn起始版本为11；ArkTS-Sta起始版本为26.0.0。
