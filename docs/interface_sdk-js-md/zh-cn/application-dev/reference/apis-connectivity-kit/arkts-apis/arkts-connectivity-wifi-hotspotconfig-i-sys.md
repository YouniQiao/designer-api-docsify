# HotspotConfig（系统接口）

Wi-Fi hotspot configuration information.

**起始版本：** 7

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为7。

**废弃版本：** 9

**替代接口：** ohos.wifiManager/wifiManager.HotspotConfig
