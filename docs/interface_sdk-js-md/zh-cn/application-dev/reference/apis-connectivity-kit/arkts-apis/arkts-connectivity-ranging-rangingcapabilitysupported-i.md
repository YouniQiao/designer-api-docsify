## nearlinkHadm

```TypeScript
nearlinkHadm: boolean
```

Indicates whether the Nearlink HADM ranging type supported.

**类型：** boolean

**起始版本：** 26.0.0

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。
