# @ohos.nfc.controller(标准NFC)

本模块主要用于管理NFC状态，包括打开和关闭NFC，读取NFC的状态等。

**起始版本：** 7

**系统能力：** SystemCapability.Communication.NFC.Core

## 导入模块

```TypeScript
import { nfcController } from 'kits/@kit.ConnectivityKit';
```
