## isPartnerAgentSupported

```TypeScript
function isPartnerAgentSupported(): boolean
```

Checks whether the current device supports the partner agent feature.

**起始版本：** 23

**ArkTS模式：** ArkTS-Dyn起始版本为23；ArkTS-Sta起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。
