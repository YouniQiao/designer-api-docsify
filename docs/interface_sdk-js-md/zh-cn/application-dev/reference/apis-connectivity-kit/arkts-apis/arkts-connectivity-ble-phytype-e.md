# PhyType

Phy type used during scan.

**起始版本：** 12

**ArkTS模式：** ArkTS-Dyn起始版本为12；ArkTS-Sta起始版本为23。

## PHY_LE_1M

```TypeScript
PHY_LE_1M = 1
```

**起始版本：** 12

**ArkTS模式：** ArkTS-Dyn起始版本为12；ArkTS-Sta起始版本为23。
