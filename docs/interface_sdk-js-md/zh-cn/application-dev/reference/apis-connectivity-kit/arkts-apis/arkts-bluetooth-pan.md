# @ohos.bluetooth.pan

Provides methods to accessing bluetooth PAN(Personal Area Networking Profile)-related capabilities.

**起始版本：** 10

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。
