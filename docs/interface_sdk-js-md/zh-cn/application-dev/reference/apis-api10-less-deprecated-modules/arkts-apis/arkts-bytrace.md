# @ohos.bytrace(性能打点)

本模块提供了追踪进程轨迹的能力，用于应用性能分析场景。开发者可以通过性能打点来追踪关键代码段的执行时间，定位性能瓶颈，优化应用性能。适用于应用启 动耗时分析、业务流程性能监控、帧率分析等场景。

> **说明：**&gt;
> - 本模块接口从API version 8开始废弃，建议使用新接口[@ohos.hiTraceMeter](../../apis-performance-analysis-kit/arkts-apis/arkts-hitracemeter.md)

**起始版本：** 7

**废弃版本：** 8

**替代接口：** [hiTraceMeter](../../apis-performance-analysis-kit/arkts-apis/arkts-hitracemeter.md)

**系统能力：** SystemCapability.HiviewDFX.HiTrace
