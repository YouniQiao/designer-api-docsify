# NetStatsInfo

获取的历史流量信息。

**起始版本：** 22

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Communication.NetManager.Core

## 导入模块

```TypeScript
import { statistics } from '@kit.NetworkKit';
```

## rxBytes

```TypeScript
rxBytes: long
```

流量下行数据（单位：字节）。

**类型：** ArkTS-Dyn: number  <br>ArkTS-Sta：long

**起始版本：** 22

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Communication.NetManager.Core
