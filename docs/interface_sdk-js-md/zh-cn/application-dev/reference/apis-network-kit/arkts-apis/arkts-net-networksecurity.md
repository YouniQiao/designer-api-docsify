# @ohos.net.networkSecurity(网络安全校验)

本模块提供网络安全校验能力。应用可以通过证书校验API完成证书校验功能。

**起始版本：** 11

**ArkTS模式：** ArkTS-Dyn起始版本为11；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Communication.NetStack

## 导入模块

```TypeScript
import { networkSecurity } from '@kit.NetworkKit';
```
