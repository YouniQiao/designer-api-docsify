# @ohos.net.ethernet(以太网连接管理)

本模块提供以太网连接管理能力，包括有线网络能力、获取有线网络的IP地址等信息。

**起始版本：** 9

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为9。

**系统能力：** SystemCapability.Communication.NetManager.Ethernet

## 导入模块

```TypeScript
import { ethernet } from '@kit.NetworkKit';
```
