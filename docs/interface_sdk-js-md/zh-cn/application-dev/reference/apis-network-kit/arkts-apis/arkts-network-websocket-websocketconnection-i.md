# WebSocketConnection

客户端信息，包括客户端的ip地址和端口号port。

**起始版本：** 19

**ArkTS模式：** ArkTS-Dyn起始版本为19；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Communication.NetStack

## 导入模块

```TypeScript
import { webSocket } from '@kit.NetworkKit';
```

## clientIP

```TypeScript
clientIP: string
```

客户端的ip地址。

**类型：** string

**起始版本：** 19

**ArkTS模式：** ArkTS-Dyn起始版本为19；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Communication.NetStack

## clientPort

```TypeScript
clientPort: int
```

客户端的端口号port。

**类型：** ArkTS-Dyn: number  <br>ArkTS-Sta：int

**起始版本：** 19

**ArkTS模式：** ArkTS-Dyn起始版本为19；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Communication.NetStack
