# IpsecVpnConfig（系统接口）

Define configuration of the ipsec VPN network.

**继承/实现关系：** IpsecVpnConfig extends [SysVpnConfig](arkts-network-vpn-sysvpnconfig-i-sys.md)

**起始版本：** 12

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为12。

**系统接口：** 此接口为系统接口。
