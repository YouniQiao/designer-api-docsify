# ChainContinue

```TypeScript
export type ChainContinue = boolean
```

Whether or not to continue process of interceptor chain.

**起始版本：** 22

**ArkTS模式：** ArkTS-Dyn起始版本为22；ArkTS-Sta起始版本为26.0.0。

**原子化服务API：** 从API版本22开始，该接口支持在原子化服务API中使用。
