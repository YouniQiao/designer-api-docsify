# L2tpVpnConfig（系统接口）

Define configuration of the l2tp VPN network.

**继承/实现关系：** L2tpVpnConfig extends [SysVpnConfig](arkts-network-vpn-sysvpnconfig-i-sys.md)

**起始版本：** 12

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为12。
