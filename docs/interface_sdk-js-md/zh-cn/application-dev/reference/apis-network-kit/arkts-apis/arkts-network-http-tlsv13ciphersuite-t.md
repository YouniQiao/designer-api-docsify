# TlsV13CipherSuite

export type TlsV13CipherSuite = TlsV12CipherSuite | TlsV13SpecificCipherSuite

**起始版本：** 18

**原子化服务API：** 从API版本18开始，该接口支持在原子化服务API中使用。
