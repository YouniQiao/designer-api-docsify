# NetworkResponse

This module provides the Network Response.

**起始版本：** 3

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为3。

**系统能力：** SystemCapability.Communication.NetManager.Core

## 导入模块

```TypeScript
```

## metered

```TypeScript
metered: boolean
```

是否按照流量计费。true：按照流量计费；false：不按照流量计费。

**类型：** boolean

**起始版本：** 3

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为3。

**系统能力：** SystemCapability.Communication.NetManager.Core

## type

```TypeScript
type: string
```

网络类型，可能的值有2g，3g，4g，5g，wifi，none等。

**类型：** string

**起始版本：** 3

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为3。

**系统能力：** SystemCapability.Communication.NetManager.Core
