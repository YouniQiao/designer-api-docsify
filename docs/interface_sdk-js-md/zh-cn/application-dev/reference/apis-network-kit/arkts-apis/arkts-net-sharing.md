# @ohos.net.sharing(网络共享管理)

网络共享管理模块用于将设备网络连接共享给其他连接设备。

**起始版本：** 9

**系统能力：** SystemCapability.Communication.NetManager.NetSharing

## 导入模块

```TypeScript
import { sharing } from 'kits/@kit.NetworkKit';
```
