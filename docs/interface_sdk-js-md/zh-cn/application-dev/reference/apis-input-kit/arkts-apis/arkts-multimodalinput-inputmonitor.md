# @ohos.multimodalInput.inputMonitor(输入监听)

输入监听模块，提供了监听输入设备事件的能力。输入设备事件当前包括触屏输入事件、鼠标输入事件和触控板输入事件。

**起始版本：** 7

**系统能力：** SystemCapability.MultimodalInput.Input.InputMonitor

**系统接口：** 此接口为系统接口。

## 导入模块

```TypeScript
import { inputMonitor } from 'kits/@kit.InputKit';
```
