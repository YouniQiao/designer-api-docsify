# SecureLevel

```TypeScript
type SecureLevel = 'S1' | 'S2' | 'S3' | 'S4'
```

表示认证的安全级别。

**起始版本：** 6

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为6。

**废弃版本：** 8

**替代接口：** [AuthTrustLevel](arkts-userauthentication-userauth-authtrustlevel-e.md)

**系统能力：** SystemCapability.UserIAM.UserAuth.Core

| --- |
| 'S1' |
| 'S2' |
| 'S3' |
