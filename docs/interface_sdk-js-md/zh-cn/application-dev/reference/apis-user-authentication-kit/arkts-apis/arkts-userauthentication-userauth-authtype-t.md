# AuthType

```TypeScript
type AuthType = 'ALL' | 'FACE_ONLY'
```

表示认证类型。

**起始版本：** 6

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为6。

**废弃版本：** 8

**替代接口：** [UserAuthType](arkts-userauthentication-userauth-userauthtype-e.md)

**系统能力：** SystemCapability.UserIAM.UserAuth.Core

| 类型 |
| --- |
| 'ALL' |
| 'FACE_ONLY' |
