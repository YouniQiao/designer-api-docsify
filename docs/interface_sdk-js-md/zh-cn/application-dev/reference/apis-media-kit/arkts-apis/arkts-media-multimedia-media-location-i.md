# Location

提供媒体资源的地理位置定义。

**起始版本：** 6

**ArkTS模式：** ArkTS-Dyn起始版本为6；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Multimedia.Media.Core

## 导入模块

```TypeScript
import { media } from '@kit.MediaKit';
```

## latitude

```TypeScript
latitude: double
```

纬度。

**类型：** ArkTS-Dyn: number  <br>ArkTS-Sta：double

**起始版本：** 6

**ArkTS模式：** ArkTS-Dyn起始版本为6；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Multimedia.Media.Core
