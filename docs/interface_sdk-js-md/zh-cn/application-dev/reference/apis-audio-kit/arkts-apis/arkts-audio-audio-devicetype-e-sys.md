# DeviceType

表示设备类型的枚举。

**起始版本：** 7

**ArkTS模式：** ArkTS-Dyn起始版本为7；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Multimedia.Audio.Device

## ACCESSORY

```TypeScript
ACCESSORY = 26
```

辅助设备（例如遥控器上的麦克风等）。

**起始版本：** 19

**ArkTS模式：** ArkTS-Dyn起始版本为19；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Multimedia.Audio.Device

**系统接口：** 此接口为系统接口。

## BLUETOOTH_SPP

```TypeScript
BLUETOOTH_SPP = 33
```

蓝牙设备SPP（Serial Port Profile）连接。

**起始版本：** 22

**ArkTS模式：** ArkTS-Dyn起始版本为22；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Multimedia.Audio.Device

**系统接口：** 此接口为系统接口。
