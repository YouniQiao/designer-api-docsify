# @ohos.bundleState(设备使用信息统计)

本模块提供设备使用信息统计能力。

**起始版本：** 7

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为7。

**废弃版本：** 9

**系统能力：** SystemCapability.ResourceSchedule.UsageStatistics.App

## 导入模块

```TypeScript
import { bundleState } from '@kit.BackgroundTasksKit';
```
