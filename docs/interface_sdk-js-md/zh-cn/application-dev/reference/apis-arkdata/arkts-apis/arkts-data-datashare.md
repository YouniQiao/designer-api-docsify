# @ohos.data.dataShare

**DataShare**用于应用管理其自身数据，同时支持同个设备上不同应用间的数据共享。

**起始版本：** 20

**ArkTS模式：** ArkTS-Dyn起始版本为9；ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.DistributedDataManager.DataShare.Consumer

## 导入模块

```TypeScript
import { dataShare } from '@kit.ArkData';
```
