# SubscribeType

订阅类型枚举。

**起始版本：** 7

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为7。

**废弃版本：** 9

**替代接口：** SubscribeType

**系统能力：** SystemCapability.DistributedDataManager.KVStore.Core

## SUBSCRIBE_TYPE_LOCAL

```TypeScript
SUBSCRIBE_TYPE_LOCAL = 0
```

表示订阅本地数据变更。

**起始版本：** 7

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为7。
