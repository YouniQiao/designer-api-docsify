# 常量

## MAX_BATCH_SIZE

```TypeScript
const MAX_BATCH_SIZE = 128
```

最大批处理操作数量。

**起始版本：** 7

**ArkTS模式：** 仅支持ArkTS-Dyn，ArkTS-Dyn起始版本为7。

**废弃版本：** 9

**替代接口：** MAX_BATCH_SIZE

**系统能力：** SystemCapability.DistributedDataManager.KVStore.Core
