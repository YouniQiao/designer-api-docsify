# BorderRadiusMode

边框圆角模式枚举，用于控制分段按钮的圆角计算方式。  
| 名称 |值 | 说明 | | ------- | - |-------------------------------- | | DEFAULT | 0 |默认模式，框架自动计算边框圆角。 | | CUSTOM | 1 |自定义模式，开发者设置边框圆角。 |

**起始版本：** 23

**ArkTS模式：** ArkTS-Sta起始版本为23。
