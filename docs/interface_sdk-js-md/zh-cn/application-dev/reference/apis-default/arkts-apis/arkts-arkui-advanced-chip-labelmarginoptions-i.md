# LabelMarginOptions

LabelMarginOptions用于定义文本与左右侧图标之间间距。

**起始版本：** 23

**ArkTS模式：** ArkTS-Sta起始版本为23。

<!--Device-unnamed-export interface LabelMarginOptions--><!--Device-unnamed-export interface LabelMarginOptions-End-->

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## 导入模块

```TypeScript
```

## left

```TypeScript
left?: Dimension
```

文本与左侧图标之间间距，不支持百分比。默认值：size为ChipSize.SMALL时，left默认值：4size为ChipSize.NORMAL时，left默认值：6单位：vp超出取值范围按默认值处理。取值范围：[0, +∞)

**类型：** Dimension

**起始版本：** 23

**ArkTS模式：** ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
