# PopoverOptions

跟手弹出框参数，用于设置弹出框内容、位置属性等。继承自CustomPopupOptions。

> **说明：**&gt;
> 气泡圆角半径radius默认值为32vp。

**继承/实现关系：** PopoverOptions extends CustomPopupOptions

**起始版本：** 23

**ArkTS模式：** ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
