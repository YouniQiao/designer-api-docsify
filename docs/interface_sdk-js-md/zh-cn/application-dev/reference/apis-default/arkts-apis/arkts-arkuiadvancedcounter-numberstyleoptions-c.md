# NumberStyleOptions

NumberStyleOptions定义了列表型和紧凑型Counter的属性和事件。

继承于[InlineStyleOptions](arkts-arkuiadvancedcounter-inlinestyleoptions-c.md)。

**继承/实现关系：** NumberStyleOptions extends [InlineStyleOptions](arkts-arkuiadvancedcounter-inlinestyleoptions-c.md)

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。
