# CounterV2NumberStyleOptions

CounterV2NumberStyleOptions定义了列表型和紧凑型CounterV2的属性和事件。

继承于[CounterV2InlineStyleOptions](../../apis-arkui/arkts-apis/arkts-arkui-arkuiadvancedcounterv2-counterv2inlinestyleoptions-c.md)。

**继承/实现关系：** CounterV2NumberStyleOptions extends [CounterV2InlineStyleOptions](../../apis-arkui/arkts-apis/arkts-arkui-arkuiadvancedcounterv2-counterv2inlinestyleoptions-c.md)

**起始版本：** 26.0.0

**ArkTS模式：** ArkTS-Sta起始版本为26.0.0。
