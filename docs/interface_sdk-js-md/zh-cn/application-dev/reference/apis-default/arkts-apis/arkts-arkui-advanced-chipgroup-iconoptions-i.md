## size

```TypeScript
size?: SizeOptions
```

图标大小，不支持百分比。

默认值：undefined

**类型：** SizeOptions

**起始版本：** 23

**ArkTS模式：** ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
