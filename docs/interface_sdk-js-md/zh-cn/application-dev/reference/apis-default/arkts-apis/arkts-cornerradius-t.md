# CornerRadius

```TypeScript
export type CornerRadius = Corners<Vector2>
```

设置四个角的圆角x轴与y轴的半轴长。

**起始版本：** 23

**ArkTS模式：** ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
