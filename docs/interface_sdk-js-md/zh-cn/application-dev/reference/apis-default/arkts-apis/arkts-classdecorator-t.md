# ClassDecorator

```TypeScript
declare type ClassDecorator = <TFunction extends Function>(target: TFunction) => TFunction | void
```

**ArkTS模式：** 仅支持ArkTS-Dyn

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| target | TFunction | 是 |  |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| TFunction \| void | - |
