# TypedPropertyDescriptor

**ArkTS模式：** 仅支持ArkTS-Dyn

## get

```TypeScript
get?: () => T
```

**ArkTS模式：** 仅支持ArkTS-Dyn

## set

```TypeScript
set?: (value: T) => void
```

**ArkTS模式：** 仅支持ArkTS-Dyn

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| value | T | 是 |  |
