# @ohos.file.keyManager

该模块提供用户密钥管理相关的常用功能：包括用户密钥卸载等。

> **说明：**&gt;
> - 当前页面仅包含本模块的系统接口。

**起始版本：** 15

**ArkTS模式：** ArkTS-Dyn起始版本为15；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.FileManagement.StorageService.Encryption

```TypeScript
import { keyManager } from '@kit.CoreFileKit';
```
