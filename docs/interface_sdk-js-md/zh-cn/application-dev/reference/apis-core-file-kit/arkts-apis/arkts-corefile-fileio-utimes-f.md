## utimes

```TypeScript
function utimes(path: string, mtime: double): void
```

更改文件上次修改该文件的时间。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.FileManagement.File.FileIO

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| path | string | 是 |
| mtime | double | 是 |

**错误码：**

| 错误码ID |
| --- |
| 13900001 |
| 13900002 |
| 13900012 |
| 13900020 |
| 13900027 |
| 13900042 |
