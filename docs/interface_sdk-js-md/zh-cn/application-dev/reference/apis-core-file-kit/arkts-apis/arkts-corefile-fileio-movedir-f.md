## moveDir

```TypeScript
function moveDir(src: string, dest: string, mode?: int): Promise<void>
```

移动源目录及其内容至目标路径下。使用Promise异步回调。

> **说明：**&gt;
> 该接口不支持在分布式文件路径下操作。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.FileManagement.File.FileIO

## moveDir

```TypeScript
function moveDir(src: string, dest: string, callback: AsyncCallback<void>): void
```

移动源目录及其内容至目标路径下。使用callback异步回调。移动模式为目录级别抛异常。当目标目录下存在与源目录名冲突的目录，则抛出异常。

> **说明：**&gt;
> 该接口不支持在分布式文件路径下操作。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.FileManagement.File.FileIO

**参数：**

| 参数名 | 类型 | 必填 |

| src | string | 是 |
