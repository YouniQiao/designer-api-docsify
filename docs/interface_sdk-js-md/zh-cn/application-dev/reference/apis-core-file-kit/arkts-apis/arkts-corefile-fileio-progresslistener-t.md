# ProgressListener

```TypeScript
type ProgressListener = (progress: Progress) => void
```

拷贝进度监听。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.FileManagement.File.FileIO

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| progress | [Progress](arkts-corefile-file-fs-progress-i.md) | 是 |
