## setxattr

```TypeScript
declare function setxattr(path: string, key: string, value: string): Promise<void>
```

**系统能力：** SystemCapability.FileManagement.File.FileIO

| 参数名 | 类型 | 必填 |

| path | string | 是 |
| key | string | 是 |
| value | string | 是 |
