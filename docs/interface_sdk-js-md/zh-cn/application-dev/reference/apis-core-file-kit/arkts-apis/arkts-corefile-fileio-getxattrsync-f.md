## getxattrSync

```TypeScript
function getxattrSync(path: string, key: string): string
```

使用同步接口获取文件或目录的扩展属性。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.FileManagement.File.FileIO

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| path | string | 是 |
| key | string | 是 |

**返回值：**

| 类型 |
| --- |
| string |
