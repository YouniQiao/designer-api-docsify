## mkdirSync

```TypeScript
declare function mkdirSync(path: string, mode?: number): void
```

**替代接口：** [mkdirSync](arkts-corefile-file-fs-mkdirsync-f.md)

**参数：**

| 参数名 | 类型 | 必填 |
| --- | --- | --- |
| path | string | 是 |
| mode | number | 否 |
