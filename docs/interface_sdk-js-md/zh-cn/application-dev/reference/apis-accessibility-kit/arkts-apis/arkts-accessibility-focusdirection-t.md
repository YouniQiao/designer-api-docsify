# FocusDirection

```TypeScript
export type FocusDirection = 'up' | 'down' | 'left' | 'right' | 'forward' | 'backward'
```

表示查询下一焦点元素的方向。

**起始版本：** 9

**ArkTS模式：** ArkTS-Dyn起始版本为9；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.BarrierFree.Accessibility.Core

| 'up' |
| 'down' |
| 'left' |
| 'right' |
