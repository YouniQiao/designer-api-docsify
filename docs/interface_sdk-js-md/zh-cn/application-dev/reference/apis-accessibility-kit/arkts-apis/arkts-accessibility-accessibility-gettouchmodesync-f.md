# getTouchModeSync

## getTouchModeSync

```TypeScript
function getTouchModeSync(): string
```

查询触摸浏览功能下的单击/双击操作模式。

**起始版本：** 20

**ArkTS模式：** ArkTS-Dyn起始版本为20；ArkTS-Sta起始版本为23。

**原子化服务API：** 从API版本23开始，该接口支持在原子化服务API中使用。

**卡片能力：** 从API版本23开始，该接口支持在ArkTS卡片中使用。
