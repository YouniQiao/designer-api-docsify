# ScrollbarLayoutPolicy

Defines the layout policy for scrollbars, used with [scrollbarLayoutPolicy](arkts-arkweb-web-webattribute-i.md#scrollbarlayoutpolicy).

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为26.0.0。

**系统能力：** SystemCapability.Web.Webview.Core

## CONTENT

```TypeScript
CONTENT = 0
```

Adheres to W3C standards (CSS/HTML/XHTML) for scrollbar layout.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Web.Webview.Core

## SYSTEM

```TypeScript
SYSTEM = 1
```

Follows the system UI conventions for scrollbar layout in the system language.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Web.Webview.Core
