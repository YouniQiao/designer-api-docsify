# OnOverScrollEvent

Defines the function Triggered when the over scrolling.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Web.Webview.Core

## xOffset

```TypeScript
xOffset: double
```

Based on the leftmost part of the page, the horizontal scroll offset is over. The unit is vp.

**类型：** double

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Web.Webview.Core

## yOffset

```TypeScript
yOffset: double
```

Based on the top of the page, the vertical scroll offset is over. The unit is vp.

**类型：** double

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Web.Webview.Core
