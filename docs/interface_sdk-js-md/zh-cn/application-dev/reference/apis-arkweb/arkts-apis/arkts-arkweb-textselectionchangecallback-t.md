# TextSelectionChangeCallback

```TypeScript
export type TextSelectionChangeCallback = (selectionText: string) => void
```

**系统能力：** SystemCapability.Web.Webview.Core

**参数：**

| 参数名 | 类型 | 必填 |

| selectionText | string | 是 |
