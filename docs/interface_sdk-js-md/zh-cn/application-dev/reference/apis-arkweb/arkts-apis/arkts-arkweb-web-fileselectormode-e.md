# FileSelectorMode

Enum type supplied to [FileSelectorParam](arkts-arkweb-web-fileselectorparam-c.md) when onFileSelectorShow being called.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Web.Webview.Core

## FILE_OPEN_MODE

```TypeScript
FILE_OPEN_MODE = 0
```

Open and upload a file.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，ArkTS-Sta起始版本为23。
