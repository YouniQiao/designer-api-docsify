# MovingPhotoView(A component which support applications to show moving photo data)

定义动态照片组件。

## MovingPhotoView

```TypeScript
MovingPhotoView(options: MovingPhotoViewOptions)
```

设置组件参数.

**起始版本：** 12

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务中使用。
