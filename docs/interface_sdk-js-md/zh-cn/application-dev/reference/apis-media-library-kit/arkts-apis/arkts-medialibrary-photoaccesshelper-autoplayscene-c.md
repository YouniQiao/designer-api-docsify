# AutoPlayScene

Defines the playback mode of the moving photo in different scenarios.

**起始版本：** 23

**ArkTS模式：** ArkTS-Dyn起始版本为23；ArkTS-Sta起始版本为26.0.0。

## playMode

```TypeScript
playMode: PlayMode
```

Whether to support automatic playback of the moving photo.

**类型：** [PlayMode](../../apis-arkui/arkts-apis/arkts-arkui-enums-playmode-e.md)

**起始版本：** 23

**ArkTS模式：** ArkTS-Dyn起始版本为23；ArkTS-Sta起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本23开始，该接口支持在原子化服务API中使用。
