## DEFAULT_PHOTO_URI

```TypeScript
DEFAULT_PHOTO_URI = 'file://media/Photo'
```

Default **PhotoAsset** URI, which must be used with **forChildUris{true}** to subscribe to change notifications of all photo assets.

**起始版本：** 10

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。
