# DeepOptimizeState（系统接口）

Describes the state type of deep optimize space.

**起始版本：** 26.0.0

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为26.0.0。

```TypeScript
RUNNING = 0
```
