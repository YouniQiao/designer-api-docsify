# CloudEnhancementTaskStage（系统接口）

[CloudEnhancementTaskState](arkts-medialibrary-photoaccesshelper-cloudenhancement-c-sys.md).

**ArkTS模式：** ArkTS-Dyn起始版本为13；ArkTS-Sta起始版本为23。
