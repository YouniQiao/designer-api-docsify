# @ohos.advertising.AdsServiceExtensionAbility(广告扩展服务)

本模块为设备厂商提供广告扩展能力，设备厂商可自主实现请求广告的回调。


## 导入模块

```TypeScript
import { AdsServiceExtensionAbility, RespCallback } from 'kits/@kit.AdsKit';
```
