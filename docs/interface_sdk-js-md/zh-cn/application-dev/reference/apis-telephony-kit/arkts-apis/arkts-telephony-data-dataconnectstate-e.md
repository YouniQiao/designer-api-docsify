# DataConnectState

描述蜂窝数据链路连接状态。

**起始版本：** 7

**ArkTS模式：** ArkTS-Dyn起始版本为7；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Telephony.CellularData

## DATA_STATE_UNKNOWN

```TypeScript
DATA_STATE_UNKNOWN = -1
```

表示蜂窝数据链路未知。

**起始版本：** 7

**ArkTS模式：** ArkTS-Dyn起始版本为7；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Telephony.CellularData
