# CallWaitingStatus（系统接口）

呼叫等待状态。

**起始版本：** 7

**ArkTS模式：** ArkTS-Dyn起始版本为7；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## CALL_WAITING_DISABLE

```TypeScript
CALL_WAITING_DISABLE = 0
```

禁用呼叫等待。

**起始版本：** 7

**ArkTS模式：** ArkTS-Dyn起始版本为7；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## CALL_WAITING_ENABLE

```TypeScript
CALL_WAITING_ENABLE = 1
```

启用呼叫等待。

**起始版本：** 7

**ArkTS模式：** ArkTS-Dyn起始版本为7；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。
