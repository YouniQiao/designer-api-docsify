# DialType（系统接口）

Indicates the types of the call to be made.

**起始版本：** 8

**ArkTS模式：** ArkTS-Dyn起始版本为8；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## DIAL_CARRIER_TYPE

