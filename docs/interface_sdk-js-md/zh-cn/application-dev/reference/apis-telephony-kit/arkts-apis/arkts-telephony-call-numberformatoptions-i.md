## countryCode

```TypeScript
countryCode?: string
```

国家码，支持所有国家的国家码，如：CN（中国）。默认为：CN。

**类型：** string

**起始版本：** 7

**ArkTS模式：** ArkTS-Dyn起始版本为7；ArkTS-Sta起始版本为23。
