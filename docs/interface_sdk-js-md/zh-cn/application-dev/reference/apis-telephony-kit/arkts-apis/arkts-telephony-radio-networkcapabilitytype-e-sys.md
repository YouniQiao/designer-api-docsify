# NetworkCapabilityType（系统接口）

Enum for network capability type.

**起始版本：** 10

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Telephony.CoreService

**系统接口：** 此接口为系统接口。
