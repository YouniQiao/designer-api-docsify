# DialOptions

拨打电话的可选参数。

**起始版本：** 6

**ArkTS模式：** ArkTS-Dyn起始版本为6；ArkTS-Sta起始版本为23。

<!--Device-call-export interface DialOptions--><!--Device-call-export interface DialOptions-End-->

**系统能力：** SystemCapability.Telephony.CallManager

## extras

```TypeScript
extras?: boolean
```

根据extras的值判断是否为视频通话，默认为语音通话。

- true：视频通话。  
- false：语音通话。

**类型：** boolean

**起始版本：** 6

**ArkTS模式：** ArkTS-Dyn起始版本为6；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Telephony.CallManager
