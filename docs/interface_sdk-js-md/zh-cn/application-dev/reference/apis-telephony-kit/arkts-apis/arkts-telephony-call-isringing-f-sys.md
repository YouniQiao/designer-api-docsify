# isRinging（系统接口）

## isRinging

```TypeScript
function isRinging(callback: AsyncCallback<boolean>): void
```

判断是否正在响铃。使用callback异步回调。

**起始版本：** 8

**ArkTS模式：** ArkTS-Dyn起始版本为8；ArkTS-Sta起始版本为23。

**需要权限：** ohos.permission.SET_TELEPHONY_STATE
