# @ohos.systemDateTime(系统时间、时区)

本模块主要由系统时间和系统时区功能组成。开发者可以获取系统时间及系统时区。

**起始版本：** 9

**系统能力：** SystemCapability.MiscServices.Time

## 导入模块

```TypeScript
import { systemDateTime } from 'kits/@kit.BasicServicesKit';
```
