# @ohos.account.appAccount(应用账号管理)

本模块提供应用账号信息的添加、删除、修改和查询基础能力。应用账号管理采用应用级账号隔离机制，每个应用的账号信息独立管理。

**起始版本：** 7

**系统能力：** SystemCapability.Account.AppAccount

## 导入模块

```TypeScript
import { appAccount } from 'kits/@kit.BasicServicesKit';
```
