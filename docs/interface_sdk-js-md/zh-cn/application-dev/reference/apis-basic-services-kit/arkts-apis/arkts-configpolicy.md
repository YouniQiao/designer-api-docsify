# @ohos.configPolicy

配置策略提供按系统预定义的定制配置层级获取对应目录和文件路径的能力。

**起始版本：** 8

**系统能力：** SystemCapability.Customization.ConfigPolicy

**系统接口：** 此接口为系统接口。

## 导入模块

```TypeScript
import { configPolicy } from 'kits/@kit.BasicServicesKit';
```
