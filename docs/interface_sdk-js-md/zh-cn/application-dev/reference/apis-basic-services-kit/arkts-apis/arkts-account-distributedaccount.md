# @ohos.account.distributedAccount

本模块提供管理分布式账号的一些基础功能，主要包括查询和更新账号登录状态。

**起始版本：** 7

**ArkTS模式：** ArkTS-Dyn起始版本为7；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Account.OsAccount

## 导入模块

```TypeScript
import { distributedAccount } from '@kit.BasicServicesKit';
```
