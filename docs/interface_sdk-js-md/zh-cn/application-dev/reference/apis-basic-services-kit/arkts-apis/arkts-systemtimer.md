# @ohos.systemTimer(系统定时器)

本模块主要由系统定时器功能组成。开发者可以使用定时功能实现定时服务，如闹钟等。

**起始版本：** 7

**系统能力：** SystemCapability.MiscServices.Time

**系统接口：** 此接口为系统接口。

## 导入模块

```TypeScript
import { systemTimer } from 'kits/@kit.BasicServicesKit';
```
