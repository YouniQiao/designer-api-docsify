# getMinHeightSync（系统接口）

## 导入模块

```TypeScript
import { wallpaper } from 'kits/@kit.BasicServicesKit';
```

## getMinHeightSync

```TypeScript
function getMinHeightSync(): number
```

获取壁纸的最小高度值。

**起始版本：** 9

**系统能力：** SystemCapability.MiscServices.Wallpaper

**系统接口：** 此接口为系统接口。

**返回值：**

| 类型 |
| --- |
| number |
