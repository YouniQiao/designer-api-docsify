# PrintResolution

定义打印分辨率的接口。

**起始版本：** 24

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Print.PrintFramework

## 导入模块

```TypeScript
import { print } from '@kit.BasicServicesKit';
```

## horizontalDpi

```TypeScript
horizontalDpi: int
```

表示水平DPI。单位：DPI。

**类型：** ArkTS-Dyn: number  <br>ArkTS-Sta：int

**起始版本：** 24

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Print.PrintFramework

## id

id: string

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。
