# StopBits

表示停止位宽的枚举，单位：比特。

**起始版本：** 19

**ArkTS模式：** ArkTS-Dyn起始版本为19；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.USB.USBManager.Serial

## STOPBIT_1

```TypeScript
STOPBIT_1 = 0
```

表示停止位宽为1比特。

**起始版本：** 19

**ArkTS模式：** ArkTS-Dyn起始版本为19；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.USB.USBManager.Serial

STOPBIT_2 = 1
