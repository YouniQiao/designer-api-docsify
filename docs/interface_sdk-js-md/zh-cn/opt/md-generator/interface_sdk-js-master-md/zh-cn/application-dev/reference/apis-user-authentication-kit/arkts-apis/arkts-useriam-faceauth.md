# @ohos.userIAM.faceAuth(人脸认证)

**faceAuth**模块是OpenHarmony用户身份认证体系（UserIAM）的重要组成部分，用于管理人脸录入功能。该模块提供了人脸认证管理的核心API，使开发者能够在应用内录入和管理人脸信息。

该模块主要用于以下场景：

- 需要实现人脸录入功能的应用。  
- 需要与系统级身份认证服务集成的场景。  
- 需要自定义人脸预览界面的应用。

**起始版本：** 9
