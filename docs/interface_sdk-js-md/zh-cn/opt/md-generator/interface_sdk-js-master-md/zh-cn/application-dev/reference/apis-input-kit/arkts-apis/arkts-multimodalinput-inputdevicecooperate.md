# @ohos.multimodalInput.inputDeviceCooperate

键鼠穿越功能模块，提供两台或多台设备组网协同后键鼠共享能力，实现键鼠输入设备的跨设备协同操作。 > **说明：**> > - 本模块接口从API Version 10开始不再维护，从API version 23开始废弃，推荐使用新接口[@ohos.cooperate](../../apis-distributed-service-kit/arkts-apis/arkts-cooperate.md#ohoscooperate) (键鼠穿越)。 > > - 本模块接口均为系统接口。

**起始版本：** 9

**废弃版本：** 23

**替代接口：** [cooperate/cooperate](../../apis-distributed-service-kit/arkts-apis/arkts-cooperate.md#ohoscooperate)
