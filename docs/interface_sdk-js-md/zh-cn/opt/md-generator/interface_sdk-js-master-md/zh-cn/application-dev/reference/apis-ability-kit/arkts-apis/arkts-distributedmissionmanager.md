# @ohos.distributedMissionManager

分布式任务管理模块提供跨设备任务管理能力，包括注册和取消任务状态监听、开始和停止同步远端设备任务列表、通过任务ID和包名进行迁移任务等。

**起始版本：** 9

**模型约束：** 此接口仅可在Stage模型下使用。
