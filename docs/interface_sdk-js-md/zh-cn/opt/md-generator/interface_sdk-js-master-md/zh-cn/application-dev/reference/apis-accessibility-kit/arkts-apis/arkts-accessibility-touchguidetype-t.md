# TouchGuideType

```TypeScript
type TouchGuideType = 'touchBegin' | 'touchEnd' | 'touchGuideGesture'
```

触摸浏览事件类型。触摸浏览是无障碍辅助功能中的一种交互模式，用户在该模式下通过触摸探索界面元素而非直接激活。

**起始版本：** 9
