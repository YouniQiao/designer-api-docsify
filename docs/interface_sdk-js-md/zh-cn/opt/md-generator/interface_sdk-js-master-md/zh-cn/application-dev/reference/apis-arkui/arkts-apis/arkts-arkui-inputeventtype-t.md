# InputEventType

```TypeScript
declare type InputEventType = TouchEvent | MouseEvent | AxisEvent
```

[postInputEvent](arkts-arkui-buildernode-c.md#postInputEvent)的参数，定义要发送的输入事件类型。

**起始版本：** 20

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本20开始，该接口支持在原子化服务API中使用。
