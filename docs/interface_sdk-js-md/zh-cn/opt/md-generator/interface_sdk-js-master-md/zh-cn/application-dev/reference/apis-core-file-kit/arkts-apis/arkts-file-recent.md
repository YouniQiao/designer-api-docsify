# @ohos.file.recent

该模块提供最近访问列表插入、移除、查询等常用能力。

> **说明：**
> 
> - 当前只支持文件管理器调用。

**起始版本：** 10

**废弃版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。
