# AVSessionType

```TypeScript
type AVSessionType = 'audio' | 'video' | 'voice_call' | 'video_call' | 'photo'
```

当前会话支持的会话类型。

该类型可取的值为下表字符串。

**起始版本：** 10

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。
