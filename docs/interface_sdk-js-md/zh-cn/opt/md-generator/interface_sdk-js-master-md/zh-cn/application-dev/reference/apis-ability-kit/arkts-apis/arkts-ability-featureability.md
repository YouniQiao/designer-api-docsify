# @ohos.ability.featureAbility

FeatureAbility模块提供与用户进行交互的Ability的能力，包括启动新的Ability、停止Ability、获取dataAbilityHelper对象、获取当前Ability对应的窗口，连接断连Service等。

**起始版本：** 6

**模型约束：** 此接口仅可在FA模型下使用。
