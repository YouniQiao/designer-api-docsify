# getPoliciesSync

## getPoliciesSync

```TypeScript
function getPoliciesSync(admin: Want, appId: string): string
```

通过appid获取指定浏览器设置的策略，适用于查询当前浏览器策略配置的场景，例如在企业设备管理应用中展示策略详情、验证策略是否生效等。

**起始版本：** 12

**模型约束：** 此接口仅可在Stage模型下使用。
