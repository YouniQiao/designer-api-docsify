# open

## open

```TypeScript
declare function open(path: string, mode?: number): Promise<File>
```

打开文件或目录，使用promise异步回调。支持使用URI打开文件。

**起始版本：** 9

**废弃版本：** -1

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。
