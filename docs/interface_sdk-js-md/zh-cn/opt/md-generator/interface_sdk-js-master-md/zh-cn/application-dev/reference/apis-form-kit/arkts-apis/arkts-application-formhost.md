# @ohos.application.formHost

formHost模块提供了卡片使用方相关接口的能力，包括对使用方同一用户下安装的卡片进行删除、释放、请求更新，获取信息、状态等操作。 > **说明：** > > 从API version 9 开始废弃， > > 本模块接口均为系统接口。

**起始版本：** 8

**废弃版本：** 9

**替代接口：** [formHost](arkts-app-form-formhost.md#ohosappformformhost)
