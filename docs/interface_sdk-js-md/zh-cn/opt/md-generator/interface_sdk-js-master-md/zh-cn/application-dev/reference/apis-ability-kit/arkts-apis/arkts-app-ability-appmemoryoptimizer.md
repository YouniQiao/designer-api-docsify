# @ohos.app.ability.appMemoryOptimizer

appMemoryOptimizer提供应用内存优化的能力，包括释放指定文件的文件页缓存、释放指定模块的文件页缓存等。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。
