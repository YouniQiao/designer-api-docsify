# @ohos.cooperate

键鼠穿越功能模块，提供两台或多台设备组网协同后键鼠共享能力，实现键鼠输入设备的跨设备协同操作。

> **说明：**
> 
> - 本模块接口均为系统接口。

**起始版本：** 10

**系统能力：** SystemCapability.Msdp.DeviceStatus.Cooperate
