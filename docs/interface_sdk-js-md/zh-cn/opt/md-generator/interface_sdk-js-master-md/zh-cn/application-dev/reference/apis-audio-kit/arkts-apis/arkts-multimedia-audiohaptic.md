# @ohos.multimedia.audioHaptic

音振协同，表示在播放声音时，可同步发起振动。可用于来电通知、消息提醒等场景。 **设备行为差异：** 若设备无振动器件，将不会产生振动效果。

**起始版本：** 23

**废弃版本：** -1
