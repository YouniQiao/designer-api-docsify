# setWantAgentMultithreading（系统接口）

## setWantAgentMultithreading

```TypeScript
function setWantAgentMultithreading(isMultithreadingSupported: boolean) : void
```

开启或者关闭WantAgent多线程传递功能。

**起始版本：** 18

**模型约束：** 此接口仅可在Stage模型下使用。
