# @ohos.commonEvent

本模块提供了公共事件的能力，包括公共事件的权限列表，发布公共事件，订阅或取消订阅公共事件，获取或修改公共事件结果代码、结果数据等。

**起始版本：** 7

**废弃版本：** 9

**替代接口：** [@ohos.commonEventManager:commonEventManager](arkts-commoneventmanager.md)
