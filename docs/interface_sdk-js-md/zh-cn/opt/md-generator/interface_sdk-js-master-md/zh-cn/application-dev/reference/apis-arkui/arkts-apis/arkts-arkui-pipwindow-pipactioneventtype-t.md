# PiPActionEventType

```TypeScript
type PiPActionEventType = PiPVideoActionEvent | PiPCallActionEvent | PiPMeetingActionEvent | PiPLiveActionEvent
```

画中画控制面板控件动作事件类型，支持以下四种。

**起始版本：** 26.0.0

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。
