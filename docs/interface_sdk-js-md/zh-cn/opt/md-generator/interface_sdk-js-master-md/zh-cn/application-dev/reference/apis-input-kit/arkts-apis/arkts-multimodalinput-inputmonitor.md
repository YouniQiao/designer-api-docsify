# @ohos.multimodalInput.inputMonitor(Input Monitor)

输入监听模块，提供了监听输入设备事件的能力。输入设备事件当前包括触屏输入事件、鼠标输入事件和触控板输入事件。

> **说明：**
> 
> - 本模块同时支持ArkTS-Dyn、ArkTS-Sta。
> 
> - 文档中“全局”表示整个触控屏或触控板。如监听全局触屏输入事件，表示触摸触控板任何位置时，整个触控板的触屏输入事件均被监听。
> 
> - 本模块接口均为系统接口。

**起始版本：** 7
