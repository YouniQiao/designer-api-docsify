# @ohos.enterprise.dateTimeManager(系统时间管理)

本模块提供系统时间管理能力。

> **说明：**
> 
> 本模块接口仅对[MDM应用](../../../mdm/mdm-kit-term.md#mdm应用)开放，需通过
> [enableAdmin](arkts-mdm-adminmanager-enableadmin-f.md#enableadmin)接口将设备管理应用激活后调用。
> 
> 本模块接口均为系统接口。

**起始版本：** 9
