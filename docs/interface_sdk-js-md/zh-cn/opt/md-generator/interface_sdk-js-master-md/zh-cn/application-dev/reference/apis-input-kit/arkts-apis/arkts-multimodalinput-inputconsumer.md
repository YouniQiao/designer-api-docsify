# @ohos.multimodalInput.inputConsumer(Global Shortcut Keys)

全局快捷键订阅模块，用于处理组合按键的订阅，本模块也支持音量键拦截监听能力。

> **说明：**
> 
> - 全局快捷键指由系统或应用定义的组合按键，系统快捷键指由系统定义的全局快捷键，应用快捷键指由应用定义的全局快捷键。

**起始版本：** 14
