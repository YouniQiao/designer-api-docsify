# startDTMF（系统接口）

## startDTMF

```TypeScript
function startDTMF(callId: number, character: string, callback: AsyncCallback<void>): void
```

启动双音多频。使用callback异步回调。

**起始版本：** 7

**需要权限：** ohos.permission.SET_TELEPHONY_STATE

