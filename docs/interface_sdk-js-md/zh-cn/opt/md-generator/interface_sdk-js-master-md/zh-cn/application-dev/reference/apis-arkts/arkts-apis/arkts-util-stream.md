# @ohos.util.stream

本模块提供基本流类型的处理能力，支持数据分块读取或写入，避免一次性加载整个数据到内存。 包括可写流（[Writable](arkts-arkts-stream-writable-c.md#Writable)）、可读流（[Readable](arkts-arkts-stream-readable-c.md#Readable)）、双工流（[Duplex](arkts-arkts-stream-duplex-c.md#Duplex)）和转换流（[Transform](arkts-arkts-stream-transform-c.md#Transform)）。

**起始版本：** 23

**废弃版本：** -1
