# @ohos.ability.particleAbility

particleAbility模块提供了操作Data和Service类型的Ability的能力，包括启动、停止指定的particleAbility，获取dataAbilityHelper，连接、断连指定的ServiceAbility等 。

**起始版本：** 7

**废弃版本：** -1

**模型约束：** 此接口仅可在FA模型下使用。
