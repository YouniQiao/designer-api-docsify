# @ohos.stationary(设备状态感知框架)

设备状态感知框架提供设备状态感知能力，包括绝对静止和相对静止，可检测设备是否处于静止或相对静止状态，适用于需要根据设备静止状态优化应用性能、智能省电、场景识别等场景。

> **说明：**
> 
> 本模块不支持在x86平台上运行。

**起始版本：** 9
