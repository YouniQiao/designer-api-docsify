# @ohos.distributedsched.linkEnhance

linkEnhance模块提供高效的蓝牙连接和数据传输功能，增强设备间连接的稳定性。使用多通道合并算法解决传统蓝牙连接不稳定、连接数量受限等问题，提升跨设备数据传输能力，改善用户使用体验。

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。
