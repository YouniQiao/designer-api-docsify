# @ohos.file.volumeManager

该模块提供卷设备、磁盘设备查询和管理的相关功能：包括查询卷设备信息，对卷设备的挂载卸载、对磁盘设备分区以及卷设备的格式化等功能。

**起始版本：** 23

**废弃版本：** -1
