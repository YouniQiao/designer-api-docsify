 [maskShape](../arkts-components/arkts-arkui-commonmethod-c.md#maskShape)接口中传入对应的形状，实现对组件的
 裁剪和遮罩效果。适用于需要将组件裁剪为圆形、椭圆、矩形等特定形状，或通过形状遮罩实现视觉效果的场景，如头像裁剪、图标遮罩等。
