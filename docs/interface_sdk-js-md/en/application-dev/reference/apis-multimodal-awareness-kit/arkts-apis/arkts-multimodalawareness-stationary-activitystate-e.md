# ActivityState

Enumerates the device statuses.

**Since:** 9

**ArkTS mode:** Supports only ArkTS-Dyn, since version 9.

**System capability:** SystemCapability.Msdp.DeviceStatus.Stationary

```TypeScript
ENTER = 1
```

**ArkTS mode:** Supports only ArkTS-Dyn, since version 9.

**System capability:** SystemCapability.Msdp.DeviceStatus.Stationary

**ArkTS mode:** Supports only ArkTS-Dyn, since version 9.
