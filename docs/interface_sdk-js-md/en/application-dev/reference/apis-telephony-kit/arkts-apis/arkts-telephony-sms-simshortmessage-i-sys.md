# SimShortMessage (System API)

Defines a SIM message.

**Since:** 7

**ArkTS mode:** ArkTS-Dyn since version 7; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Telephony.SmsMms

**System API:** This is a system API.
