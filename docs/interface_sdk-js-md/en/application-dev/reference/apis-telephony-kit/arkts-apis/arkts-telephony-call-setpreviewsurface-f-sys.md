# setPreviewSurface (System API)

## Modules to Import

```TypeScript
import { call } from '@kit.TelephonyKit';
```

## setPreviewSurface

```TypeScript
function setPreviewSurface(callId: int, surfaceId: string): Promise<void>
```

Sets the local preview window. This API uses a promise to return the result.

**Since:** 11

**ArkTS mode:** ArkTS-Dyn since version 11; ArkTS-Sta since version 23.

**Required permissions:** ohos.permission.SET_TELEPHONY_STATE

**System capability:** SystemCapability.Telephony.CallManager

**System API:** This is a system API.

**Parameters:**

| [Name](../../apis-contacts-kit/arkts-apis/arkts-contacts-contact-name-c.md) | [Type](../../apis-arkts/arkts-apis/arkts-arkts-util-type-e.md) | Mandatory |
| --- | --- | --- |
| callId | ArkTS-Dyn: number<br>ArkTS-Sta：int | Yes |
| surfaceId | string | Yes |

**Return value:**

| [Type](../../apis-arkts/arkts-apis/arkts-arkts-util-type-e.md) |
| --- |
| Promise & lt;void & gt; |
