# DialOptions

Provides an option for determining whether a call is a video call.

## extras

```TypeScript
extras?: boolean
```

Whether the call is a video call.

- **true**: video call  
- **false** (default): voice call

**Type:** boolean

**Since:** 6

**System capability:** SystemCapability.Telephony.CallManager
