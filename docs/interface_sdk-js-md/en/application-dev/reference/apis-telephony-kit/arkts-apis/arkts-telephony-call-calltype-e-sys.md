# CallType (System API)

Enumerates call types.

**Since:** 7

**ArkTS mode:** ArkTS-Dyn since version 7; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Telephony.CallManager

**System API:** This is a system API.
