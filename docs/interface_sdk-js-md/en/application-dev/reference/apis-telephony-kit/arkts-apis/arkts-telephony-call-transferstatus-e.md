# TransferStatus

Enumerates call transfer states.

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Dyn since version 8; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Telephony.CallManager

## TRANSFER_DISABLE

```TypeScript
TRANSFER_DISABLE = 0
```

Call transfer disabled.

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Dyn since version 8; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Telephony.CallManager

## TRANSFER_ENABLE

```TypeScript
TRANSFER_ENABLE = 1
```

Call transfer enabled.

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Dyn since version 8; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Telephony.CallManager
