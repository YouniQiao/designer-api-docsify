## countryCode

```TypeScript
countryCode?: string
```

Country code, for example, **CN** (China). All country codes are supported. The default value is **CN**.

**Type:** string

**Since:** 7

**ArkTS mode:** ArkTS-Dyn since version 7; ArkTS-Sta since version 23.
