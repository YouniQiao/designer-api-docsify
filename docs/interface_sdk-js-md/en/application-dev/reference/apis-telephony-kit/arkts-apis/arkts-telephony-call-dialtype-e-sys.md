# DialType (System API)

Enumerates dialup types.

**Since:** 8

**ArkTS mode:** ArkTS-Dyn since version 8; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Telephony.CallManager

**System API:** This is a system API.

## DIAL_CARRIER_TYPE

```TypeScript
DIAL_CARRIER_TYPE = 0
```

Carrier.

**Since:** 8

**ArkTS mode:** ArkTS-Dyn since version 8; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Telephony.CallManager

**System API:** This is a system API.
