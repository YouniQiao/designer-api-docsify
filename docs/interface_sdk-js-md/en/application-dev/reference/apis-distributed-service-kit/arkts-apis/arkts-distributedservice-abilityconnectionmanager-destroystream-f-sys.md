## destroyStream

```TypeScript
function destroyStream(streamId: int): void
```

Destroy the Stream.

**Since:** 18

**ArkTS mode:** ArkTS-Dyn since version 18; ArkTS-Sta since version 23.

**Model restriction:** This API can be used only in the stage model.
