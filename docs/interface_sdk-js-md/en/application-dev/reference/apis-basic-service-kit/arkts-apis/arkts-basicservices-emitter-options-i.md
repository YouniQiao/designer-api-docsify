**Deprecated since:** -1

## priority


**Type:** [EventPriority](arkts-basicservices-emitter-eventpriority-e.md)

**Since:** 23

**ArkTS mode:** ArkTS-Dyn only, since version 23.

**Deprecated since:** -1
