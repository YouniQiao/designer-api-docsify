# SelectionType

定义划词方式枚举值。

| 名称 | 值 | 说明 |  
| ------------ | -- | ------------------ |  
| MOUSE_MOVE | 1 | 鼠标或触控板滑动划词。 |  
| DOUBLE_CLICK | 2 | 鼠标或触控板双击划词。 |  
| TRIPLE_CLICK | 3 | 鼠标或触控板三击划词。 |

**Since:** 24

**ArkTS mode:** ArkTS-Dyn since version 20; ArkTS-Sta since version 24.
