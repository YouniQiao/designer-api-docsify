# @ohos.brightness

该模块提供屏幕亮度的设置接口。

> **说明：**
> 
> - 本模块接口为系统接口。

**Since:** 7

**ArkTS mode:** ArkTS-Dyn since version 7; ArkTS-Sta since version 23.

**System API:** This is a system API.

import { brightness } from 'kits/@kit.BasicServicesKit';
