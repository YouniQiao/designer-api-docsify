# PreviewAttribute

Defines the print preview attributes.

**Since:** 24

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.

<!--Device-print-interface PreviewAttribute--><!--Device-print-interface PreviewAttribute-End-->

**System capability:** SystemCapability.Print.PrintFramework

## previewRange

```TypeScript
previewRange: PrinterRange
```

Preview page range.

**Type:** PrinterRange

**Since:** 24

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.

<!--Device-PreviewAttribute-previewRange: PrinterRange--><!--Device-PreviewAttribute-previewRange: PrinterRange-End-->

**System capability:** SystemCapability.Print.PrintFramework

## result

```TypeScript
result?: int
```

Print preview result. The default value is **-1**.

**Type:** int

**Since:** 24

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.
