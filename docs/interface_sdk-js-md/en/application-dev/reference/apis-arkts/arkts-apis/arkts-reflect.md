# Reflect

Core namespace for reflection operations, providing access to metadata such as classes, interfaces, methods, and properties at runtime.

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Sta since version 26.0.0.

**Model restriction:** This API can be used only in the stage model.
