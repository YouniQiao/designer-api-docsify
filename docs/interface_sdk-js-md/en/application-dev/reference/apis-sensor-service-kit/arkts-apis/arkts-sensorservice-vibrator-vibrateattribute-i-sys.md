# VibrateAttribute

马达振动属性。用于  
[startVibration](arkts-sensorservice-vibrator-startvibration-f.md#startvibration)接口的attribute参数，指定马达ID、设备ID和振动使用场景。

**Since:** 9

**ArkTS mode:** ArkTS-Dyn since version 9; ArkTS-Sta since version 23.
