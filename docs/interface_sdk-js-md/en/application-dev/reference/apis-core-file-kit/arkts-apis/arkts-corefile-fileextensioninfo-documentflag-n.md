# DocumentFlag

Defines the values of **mode** used in **FileInfo**.

**Since:** 9

**ArkTS mode:** ArkTS-Dyn only, since version 9.

**Deprecated since:** 23

**Model restriction:** This API can be used only in the stage model.

**System API:** This is a system API.
