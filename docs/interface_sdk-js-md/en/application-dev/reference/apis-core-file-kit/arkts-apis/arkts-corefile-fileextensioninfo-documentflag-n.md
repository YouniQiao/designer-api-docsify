# DocumentFlag

组成FileInfo中的mode字段，通过与运算判断是否具备某种能力。

**Since:** 9

**ArkTS mode:** ArkTS-Dyn only, since version 9.

**Deprecated since:** 23

**Model restriction:** This API can be used only in the stage model.
