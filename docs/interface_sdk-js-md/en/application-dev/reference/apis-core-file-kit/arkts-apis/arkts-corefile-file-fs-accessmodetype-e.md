# AccessModeType

枚举，表示需要校验的具体权限。若不填，默认校验文件是否存在。

**Since:** 12

**ArkTS mode:** ArkTS-Dyn only, since version 12.

**System capability:** SystemCapability.FileManagement.File.FileIO
