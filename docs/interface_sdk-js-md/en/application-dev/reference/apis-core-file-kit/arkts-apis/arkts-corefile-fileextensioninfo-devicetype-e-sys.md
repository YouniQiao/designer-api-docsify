# DeviceType (System API)

组成RootInfo中的deviceType字段，表明此设备的类型。

**Since:** 9

**ArkTS mode:** ArkTS-Dyn only, since version 9.

**Deprecated since:** 23

**System capability:** SystemCapability.FileManagement.UserFileService

**System API:** This is a system API.
