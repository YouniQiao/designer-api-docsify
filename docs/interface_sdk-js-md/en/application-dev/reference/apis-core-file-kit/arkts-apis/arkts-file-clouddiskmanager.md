# @ohos.file.cloudDiskManager

本模块是为系统文件管理应用提供获取三方网盘注册的同步根信息的能力。

**Since:** 21

**ArkTS mode:** ArkTS-Dyn since version 21; ArkTS-Sta since version 23.
