# BackgroundPlayMode

表示session支持的后台播放模式的枚举。

| 名称 | 值 | 说明 |  
| ------------------------- | - | ----------------------- |  
| ENABLE_BACKGROUND_PLAY | 0 | 支持后台播放。 |  
| DISABLE_BACKGROUND_PLAY | 1 | 不支持后台播放。 |

**Since:** 24

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 24.
