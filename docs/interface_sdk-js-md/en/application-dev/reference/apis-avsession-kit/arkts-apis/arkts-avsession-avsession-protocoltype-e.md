## TYPE_LOCAL

```TypeScript
TYPE_LOCAL = 0
```

本地设备，包括设备本身的内置扬声器或音频插孔、A2DP 设备。

**Since:** 11

**ArkTS mode:** ArkTS-Dyn since version 11; ArkTS-Sta since version 23.

**Atomic service API:** This API can be used in atomic services since API version 12.
