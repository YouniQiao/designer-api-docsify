# ResolutionLevel

枚举，设备所支持的分辨率。

**Since:** 19

**ArkTS mode:** ArkTS-Dyn since version 19; ArkTS-Sta since version 23.

## RESOLUTION_480P

```TypeScript
RESOLUTION_480P = 0
```

**Since:** 19

**ArkTS mode:** ArkTS-Dyn since version 19; ArkTS-Sta since version 23.

**Atomic service API:** This API can be used in atomic services since API version 19.
