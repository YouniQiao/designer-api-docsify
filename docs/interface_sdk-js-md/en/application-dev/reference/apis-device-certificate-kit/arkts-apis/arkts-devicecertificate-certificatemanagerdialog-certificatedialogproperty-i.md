## showInstallButton

```TypeScript
showInstallButton: boolean
```

表示是否显示安装证书的按钮，true为显示，false为不显示。

**Type:** boolean

**Since:** 18

**ArkTS mode:** ArkTS-Dyn since version 18; ArkTS-Sta since version 23.

**Model restriction:** This API can be used only in the stage model.
