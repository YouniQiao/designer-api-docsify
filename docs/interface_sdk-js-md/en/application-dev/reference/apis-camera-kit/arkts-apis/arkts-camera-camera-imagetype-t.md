# ImageType

```TypeScript
type ImageType = image.Image | image.Picture
```

图片容器类型，用于获取全质量图和未压缩图(YUV)。

**Since:** 23

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 23.

**Atomic service API:** This API can be used in atomic services since API version 23.

| --- | --- |
