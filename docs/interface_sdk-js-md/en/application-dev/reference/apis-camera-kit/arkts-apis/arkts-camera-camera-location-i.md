# Location

Describes the geolocation information.

**Since:** 10

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Multimedia.Camera.Core

## Modules to Import

```TypeScript
import { camera } from '@kit.CameraKit';
```

## altitude

```TypeScript

```

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.
