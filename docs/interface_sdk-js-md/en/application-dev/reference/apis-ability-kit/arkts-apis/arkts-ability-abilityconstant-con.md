# Constants

## REASON_MESSAGE_DESKTOP_SHORTCUT

```TypeScript
const REASON_MESSAGE_DESKTOP_SHORTCUT: string
```

The UIAbility is launched via a home screen shortcut. If this string is obtained from the **launchReasonMessage** property in [LaunchParam](arkts-ability-abilityconstant-launchparam-i.md#LaunchParam), the UIAbility is initiated by touching a shortcut on the home screen.

**Since:** 23

**ArkTS mode:** ArkTS-Dyn only, since version 23.

**Deprecated since:** -1

**Model restriction:** This API can be used only in the stage model.
