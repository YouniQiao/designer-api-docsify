# AppVersionInfo

应用版本信息，可以通过  
[getAppVersionInfo](../../../reference/apis-ability-kit/js-apis-inner-app-context.md#contextgetappversioninfo7)获取当前应用的版本信息。

**Since:** 7

**ArkTS mode:** ArkTS-Dyn only, since version 7.
