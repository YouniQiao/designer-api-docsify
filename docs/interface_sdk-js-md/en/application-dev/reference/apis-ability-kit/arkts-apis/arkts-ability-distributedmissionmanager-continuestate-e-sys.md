# ContinueState (System API)

当前任务流转状态的枚举。

**Since:** 10

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.

## ACTIVE

```TypeScript
ACTIVE = 0
```

表示当前任务流转处于激活状态。

**Since:** 10

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.

**Model restriction:** This API can be used only in the stage model.
