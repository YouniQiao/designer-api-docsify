# AbilityStartCallback

```TypeScript
export type AbilityStartCallback = _AbilityStartCallback
```

Defines the callback invoked to return the UIExtensionAbility startup result. It is usually used as an input parameter in  
[UIAbilityContext.startAbilityByType](arkts-ability-uiabilitycontext-c.md#startAbilityByType) or  
[UIExtensionContext.startAbilityByType](arkts-ability-app-ability-uiextensioncontentsession-uiextensioncontentsession-c.md#startAbilityByType).

**Since:** 11

**ArkTS mode:** ArkTS-Dyn since version 11; ArkTS-Sta since version 23.

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 11.
