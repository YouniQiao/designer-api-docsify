# SkillInfoFlag

技能信息标志，指示需要获取的技能信息的内容。

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Dyn only, since version 26.0.0.

<!--Device-skillManager-export enum SkillInfoFlag--><!--Device-skillManager-export enum SkillInfoFlag-End-->

**System capability:** SystemCapability.BundleManager.BundleFramework.Core

## GET_SKILL_INFO_DEFAULT

```TypeScript
GET_SKILL_INFO_DEFAULT = 0x00000000
```

获取默认技能信息，不包含description、srcEntries、permissions和requestPermissions。

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Dyn only, since version 26.0.0.

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 26.0.0.
