# PermissionDef (System API)

The module provides permission details defined in the  
\_\_\_MD\_LINK\_DESC\_USD\_0\_\_\_ file. The information can be obtained using  
[bundleManager.getPermissionDef]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_.
    **NOTE**  
    
    The APIs provided by this module are system APIs.

**Since:** 9

**ArkTS mode:** ArkTS-Dyn since version 9; ArkTS-Sta since version 23.
