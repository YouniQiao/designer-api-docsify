# LauncherAbilityInfo

The module describes the ability information of the launcher application. The information can be obtained by calling  
[getLauncherAbilityInfoSync]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_\_\_\_MD\_COMMENT\_DESC\_USD\_2\_\_\_ or  
[getLauncherAbilityInfo]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_\_\_\_MD\_COMMENT\_DESC\_USD\_3\_\_\_.

**Since:** 18

**ArkTS mode:** ArkTS-Dyn since version 18; ArkTS-Sta since version 23.
