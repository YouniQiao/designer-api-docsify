# UIAbilityContext

```TypeScript
export type UIAbilityContext = _UIAbilityContext.default
```

Defines the context environment for the [UIAbility](arkts-ability-app-ability-uiability-uiability-c.md). It inherits from Context.

**Since:** 9

**ArkTS mode:** ArkTS-Dyn since version 9; ArkTS-Sta since version 23.

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 11.

**System capability:** SystemCapability.Ability.AbilityRuntime.Core

**Property type:** _UIAbilityContext.default
