# OnGetConfigurationStrategyFn (System API)

```TypeScript
export type OnGetConfigurationStrategyFn = () => ConfigurationStrategy
```

Defines the function type of the callback that returns the configuration strategy of the UIExtensionAbility.

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.

<!--Device-unnamed-export type OnGetConfigurationStrategyFn = () => ConfigurationStrategy--><!--Device-unnamed-export type OnGetConfigurationStrategyFn = () => ConfigurationStrategy-End-->

**System capability:** SystemCapability.Ability.AbilityRuntime.Core

**System API:** This is a system API.

**Return value:**

| Type | Description |
| --- | --- |
| [ConfigurationStrategy](arkts-ability-app-ability-uiextensionability-configurationstrategy-i-sys.md) | The configuration strategy of the UIExtensionAbility. |
