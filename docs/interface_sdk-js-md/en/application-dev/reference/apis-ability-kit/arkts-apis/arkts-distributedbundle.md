# @ohos.distributedBundle

本模块提供分布式包的管理。

> **说明：**
> 
> 从API version 9开始，该模块不再维护，建议使用
> [@ohos.bundle.distributedBundleManager](arkts-bundle-distributedbundlemanager.md)替代。
> 
> 本模块为系统接口。

**Since:** 8

**ArkTS mode:** ArkTS-Dyn only, since version 8.

**Deprecated since:** 9

**Substitutes:** [@ohos.bundle.distributedBundleManager:distributedBundleManager](arkts-bundle-distributedbundlemanager.md)
