## EFFICIENCY_MODE

```TypeScript
EFFICIENCY_MODE = 1
```

效率模式，不会跟随系统进入能效模式，进入能效模式后获取到的CPU资源更少。

**Since:** 20

**ArkTS mode:** ArkTS-Dyn since version 20; ArkTS-Sta since version 23.
