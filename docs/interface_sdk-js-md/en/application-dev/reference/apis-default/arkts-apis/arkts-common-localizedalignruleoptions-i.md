# LocalizedAlignRuleOptions

Defines the Localized align rule options of relative container.

**Since:** 23

**ArkTS mode:** ArkTS-Sta since version 23.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## bias

```TypeScript
bias?: Bias
```

Offset of the component under the anchor constraints. <br>The value is the ratio of the distance to the left/upper anchor to the total distance between anchors.

**Type:** [Bias](../../apis-arkui/arkts-apis/arkts-arkui-bias-i.md)

**Default:** {horizontal:0.5,vertical:0.5}

**Since:** 23

**ArkTS mode:** ArkTS-Sta since version 23.

**Model restriction:** This API can be used only in the stage model.
