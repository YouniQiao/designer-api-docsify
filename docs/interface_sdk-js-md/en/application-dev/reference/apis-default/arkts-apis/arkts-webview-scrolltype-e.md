# ScrollType

Enum type supplied to [setScrollable](arkts-webview-webviewcontroller-c.md#setscrollable) for indicating the type of scroll.

**Since:** 23

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 23.

<!--Device-webview-enum ScrollType--><!--Device-webview-enum ScrollType-End-->

**System capability:** SystemCapability.Web.Webview.Core

## EVENT

```TypeScript
EVENT = 0
```

Indicates scrolling the web page through scroll event, include touch screen, touch pad, and mouse wheel.

**Since:** 23

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 23.
