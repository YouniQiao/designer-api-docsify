# PixelStretchEffectOptions

Set the edge blur effect distance of the corresponding defense line of the component When the component expand out, no re-layout is triggered

**Since:** 23

**ArkTS mode:** ArkTS-Sta since version 23.

<!--Device-unnamed-export declare interface PixelStretchEffectOptions--><!--Device-unnamed-export declare interface PixelStretchEffectOptions-End-->

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## bottom

```TypeScript
bottom?: Length
```

bottom property. value range (-∞, ∞) If value &gt; 0, expand outward elements. Else first shrink by value and then expand outward pixels.

**Type:** [Length](../../apis-arkui/arkts-apis/arkts-arkui-length-t.md)

**Default:** 0

**Since:** 23

**ArkTS mode:** ArkTS-Sta since version 23.

**Model restriction:** This API can be used only in the stage model.
