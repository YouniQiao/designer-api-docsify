# WebLayoutMode

Enum type supplied to [layoutMode](arkts-web-attribute.md#layoutmode) for setting the web layout mode.

**Since:** 23

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 23.
