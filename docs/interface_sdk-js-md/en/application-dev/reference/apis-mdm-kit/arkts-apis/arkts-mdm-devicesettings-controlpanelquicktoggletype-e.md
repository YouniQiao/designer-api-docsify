# ControlPanelQuickToggleType

```TypeScript
enum ControlPanelQuickToggleType
```

Enumerates control panel quick toggle list icons (1*1 area). Different devices may support different toggles. If a toggle is not supported by the current device, the setting does not take effect, and the control panel does not display the corresponding icon.

**Since:** 26.1.0
