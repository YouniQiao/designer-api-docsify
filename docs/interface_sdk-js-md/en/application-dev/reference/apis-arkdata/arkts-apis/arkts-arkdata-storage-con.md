# Constants

## MAX_KEY_LENGTH

```TypeScript
const MAX_KEY_LENGTH: 80
```

key的最大长度限制为80字节。

**Since:** 6

**ArkTS mode:** ArkTS-Dyn only, since version 6.

**Deprecated since:** 9

## MAX_VALUE_LENGTH

```TypeScript
const MAX_VALUE_LENGTH: 8192
```

value的最大长度限制为16MB。

**Since:** 6

**ArkTS mode:** ArkTS-Dyn only, since version 6.

**Deprecated since:** 9
