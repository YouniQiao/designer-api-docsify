# FormType

内容卡片类型枚举，提供了大、中、小三种尺寸。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

<!--Device-unnamed-declare enum FormType--><!--Device-unnamed-declare enum FormType-End-->

**System capability:** SystemCapability.DistributedDataManager.UDMF.Core

## TYPE_BIG

```TypeScript
TYPE_BIG = 0
```

表示 4 x 4 的尺寸。默认卡片宽度为200，默认高度为200。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.

<!--Device-FormType-TYPE_BIG = 0--><!--Device-FormType-TYPE_BIG = 0-End-->

**System capability:** SystemCapability.DistributedDataManager.UDMF.Core

## TYPE_MID

```TypeScript
TYPE_MID = 1
```

表示 4 x 2 的尺寸。默认卡片宽度为200，默认高度为100。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.

<!--Device-FormType-TYPE_MID = 1--><!--Device-FormType-TYPE_MID = 1-End-->

## TYPE_SMALL

```TypeScript
TYPE_SMALL = 2
```

表示 2 x 1 的尺寸。默认卡片宽度为137， 默认高度为83。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
