# ValueType

```TypeScript
type ValueType = number | string | boolean
```

用于表示允许的数据字段类型。

**Since:** 7

**ArkTS mode:** ArkTS-Dyn only, since version 7.

| Type | Description |
| --- | --- |
| number | 表示值类型为数字。 |
| string | 表示值类型为字符串。 |
| boolean | 表示值类型为布尔值。 |
