# PRIKeyType

```TypeScript
type PRIKeyType = long | double | string
```

用于表示数据库表某一行主键的数据类型。

**Since:** 10

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.

| Type | Description |

| double | 主键的类型可以是双精度浮点型。 |
| string | 主键的类型可以是string。 |
