# TemplateId (System API)

Defines the **TemplateId** struct. **TemplateId** is generated by [**addTemplate**](arkts-arkdata-datashare-datasharehelper-i-sys.md#addTemplate) to identify a template.

**Since:** 23

**ArkTS mode:** ArkTS-Dyn only, since version 23.

**Deprecated since:** -1

<!--Device-dataShare-interface TemplateId--><!--Device-dataShare-interface TemplateId-End-->

**System capability:** SystemCapability.DistributedDataManager.DataShare.Consumer

**System API:** This is a system API.

## Modules to Import

```TypeScript
import { dataShare } from 'dataShare';
```

## bundleNameOfOwner

```TypeScript
bundleNameOfOwner: string
```

Bundle name of the template owner. The value must be the same as the **bundleName** in [**addTemplate**](arkts-arkdata-datashare-datasharehelper-i-sys.md#addTemplate).

**Type:** string

**Since:** 23

**ArkTS mode:** ArkTS-Dyn only, since version 23.

**Deprecated since:** -1

**Model restriction:** This API can be used only in the stage model.

## subscriberId

```TypeScript
subscriberId: string
```

ID of the subscriber who handles the callback. The value must the same as the **subscriberId** in [**addTemplate**](arkts-arkdata-datashare-datasharehelper-i-sys.md#addTemplate). The ID of each subscriber must be unique.

**Type:** string

**Since:** 23

**ArkTS mode:** ArkTS-Dyn only, since version 23.

**Deprecated since:** -1

**Model restriction:** This API can be used only in the stage model.
