# @ohos.data.uniformDataStruct

As a part of the Unified Data Management Framework (UDMF), the **uniformDataStruct** module provides data structs corresponding to certain  
[UniformDataTypes]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_ for service scenarios of many-to-many data sharing across applications. It helps simplify data interaction and reduce the data type adaptation workload.

**Since:** 12

**ArkTS mode:** ArkTS-Dyn since version 12; ArkTS-Sta since version 23.
