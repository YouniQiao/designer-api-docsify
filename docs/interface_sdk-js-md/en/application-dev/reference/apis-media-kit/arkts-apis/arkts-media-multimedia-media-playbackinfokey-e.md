## IS_DOWNLOADING

```TypeScript
IS_DOWNLOADING = 'is_downloading'
```

表示下载状态，1表示在下载状态，0表示非下载状态（下载完成），其对应键值类型为number。

**Since:** 12

**ArkTS mode:** ArkTS-Dyn since version 12; ArkTS-Sta since version 23.
