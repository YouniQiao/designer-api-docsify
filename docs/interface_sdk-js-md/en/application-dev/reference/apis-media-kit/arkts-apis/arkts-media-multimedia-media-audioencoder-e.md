# AudioEncoder

> **说明：**
> > 从API version 6开始支持，从API version 8开始废弃，建议使用[CodecMimeType](media.CodecMimeType)替代。

表示音频编码格式的枚举。

**Since:** 6

**ArkTS mode:** ArkTS-Dyn only, since version 6.

**Deprecated since:** 8

**Substitutes:** media.CodecMimeType
