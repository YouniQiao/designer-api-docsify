# AVMimeTypes

Enumerates the MIME type, which is set by using [setMimeType](arkts-media-media-mediasource-i.md#setMimeType).

**Since:** 23

**ArkTS mode:** ArkTS-Dyn only, since version 23.

**Deprecated since:** -1

APPLICATION_M3U8 = 'application/m3u8'

**ArkTS mode:** ArkTS-Dyn only, since version 23.
