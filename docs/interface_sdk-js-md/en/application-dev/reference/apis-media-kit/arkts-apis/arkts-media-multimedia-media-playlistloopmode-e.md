# PlaylistLoopMode

表示播放列表循环模式的枚举。

**Since:** 26.0.0

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 26.0.0.

## PLAYLIST_LOOP_MODE_ALL

```TypeScript

```

**Since:** 26.0.0

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 26.0.0.
