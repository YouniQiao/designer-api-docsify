# Progress (System API)

progress info of batch operations.

**Since:** 26.0.0

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 26.0.0.

**System capability:** SystemCapability.FileManagement.PhotoAccessHelper.Core
