## getPointerColorSync

```TypeScript
function getPointerColorSync(): number
```

Obtains the pointer color. This API returns the result synchronously.

**Since:** 10

**System capability:** SystemCapability.MultimodalInput.Input.Pointer

**System API:** This is a system API.
