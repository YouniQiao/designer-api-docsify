## CAPS_LOCK

```TypeScript
CAPS_LOCK = 1
```

CapsLock key. This key can be enabled or disabled only for the input keyboard extension.

**Since:** 15

**ArkTS mode:** ArkTS-Dyn since version 15; ArkTS-Sta since version 23.
