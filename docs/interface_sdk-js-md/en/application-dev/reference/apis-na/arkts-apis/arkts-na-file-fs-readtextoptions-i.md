## encoding

```TypeScript
encoding?: string
```

Format of the data to be encoded. This parameter is valid only when the data type is string. The default value is 'utf-8', which is the only value supported.

**Type:** string

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.
