# concat

## concat

```TypeScript
export function concat(self: FixedArray<boolean>, fst: FixedArray<boolean>, ...more: FixedArray<FixedArray<boolean>>): 
    FixedArray<boolean>
```

Combines two or more arrays by concatenating the array of arrays provided in arguments into a new array.

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Sta only, since version 26.0.0.

**Deprecated since:** -1

**Model restriction:** This API can be used only in the stage model.

**Parameters:**

| Name | Type | Mandatory | Description |
| --- | --- | --- | --- |
| self | FixedArray&lt;boolean&gt; | Yes | The array to operate `concat` on. |
| fst | FixedArray&lt;boolean&gt; | Yes | The first array to concatenate. |
| more | FixedArray&lt;FixedArray&lt;boolean&gt;&gt; | Yes | Additional arrays to concatenate. |

**Return value:**

| Type | Description |
| --- | --- |
