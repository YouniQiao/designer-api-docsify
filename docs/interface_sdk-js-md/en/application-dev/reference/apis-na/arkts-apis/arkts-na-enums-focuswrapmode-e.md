# FocusWrapMode

Focus wrap mode of a list or grid when moving focus using the arrow keys.

**Since:** 26.0.0

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 26.0.0.

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 26.0.0.
