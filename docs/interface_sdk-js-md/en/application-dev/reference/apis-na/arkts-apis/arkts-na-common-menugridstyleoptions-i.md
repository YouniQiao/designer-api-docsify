# MenuGridStyleOptions

Defines grid style of menu.

**Since:** 26.0.0

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 26.0.0.

## count

```TypeScript
count?: int
```

The count of items in grid.

**Type:** int

**Default:** 3

**Since:** 26.0.0

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 26.0.0.

**Model restriction:** This API can be used only in the stage model.
