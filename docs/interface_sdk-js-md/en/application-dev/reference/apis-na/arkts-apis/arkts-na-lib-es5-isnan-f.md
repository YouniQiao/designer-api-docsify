# isNaN

## isNaN

```TypeScript
declare function isNaN(number: number): boolean
```

Returns a Boolean value that indicates whether a value is the reserved value NaN (not a number).

**Since:** -1

**ArkTS mode:** ArkTS-Dyn only, since version -1.
