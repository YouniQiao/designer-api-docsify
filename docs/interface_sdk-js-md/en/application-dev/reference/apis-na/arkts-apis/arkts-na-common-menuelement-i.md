## enabled

```TypeScript
enabled?: boolean
```

If the value is true, the menu element is available and can respond to operations such as clicking. If the value is false, the menu element is not available and click operations are not responded.

**Type:** boolean

**Default:** true

**Since:** 23

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 23.
