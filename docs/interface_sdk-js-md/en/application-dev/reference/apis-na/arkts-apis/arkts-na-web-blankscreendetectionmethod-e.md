# BlankScreenDetectionMethod

The methods can be chosen to detect if current page is blank or nearly blank.

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Deprecated since:** -1

## DETECTION_CONTENTFUL_NODES_SEVENTEEN

```TypeScript
DETECTION_CONTENTFUL_NODES_SEVENTEEN = 0
```

This detection method is used to probe whether there are rendered contentful nodes at 17 coordinates distributed around the center of the page.

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Deprecated since:** -1
