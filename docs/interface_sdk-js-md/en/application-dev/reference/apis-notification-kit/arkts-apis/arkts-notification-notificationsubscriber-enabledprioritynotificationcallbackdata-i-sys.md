## enable

```TypeScript
readonly enable: boolean
```

所有通知的优先使能状态。  
- true：允许设置为优先通知。  
- false：禁止设置为优先通知。

**Type:** boolean

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 23.
