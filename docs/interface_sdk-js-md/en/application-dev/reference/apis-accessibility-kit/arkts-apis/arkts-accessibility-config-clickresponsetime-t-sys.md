# ClickResponseTime (System API)

```TypeScript
type ClickResponseTime = 'Short' | 'Medium' | 'Long'
```

Defines the length of time for a click.

**Since:** 23

**ArkTS mode:** ArkTS-Dyn only, since version 23.

**Deprecated since:** -1
