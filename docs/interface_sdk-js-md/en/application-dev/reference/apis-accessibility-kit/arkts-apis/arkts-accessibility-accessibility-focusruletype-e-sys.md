Enumerates the focus rule types.

**ArkTS mode:** ArkTS-Dyn only, since version 26.0.0.

**Deprecated since:** -1

## DEFAULT

```TypeScript

```

Default focus type. Nodes are not filtered by a specific type, and all nodes can be focus targets.

**ArkTS mode:** ArkTS-Dyn only, since version 26.0.0.
