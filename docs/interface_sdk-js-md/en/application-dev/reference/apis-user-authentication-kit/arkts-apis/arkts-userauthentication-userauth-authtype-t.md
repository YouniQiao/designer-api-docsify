# AuthType

```TypeScript
type AuthType = 'ALL' | 'FACE_ONLY'
```

Enumerates the authentication types.

**Since:** 6

**ArkTS mode:** ArkTS-Dyn only, since version 6.

**Deprecated since:** 8

**Substitutes:** [userAuth.UserAuthType](arkts-userauthentication-userauth-userauthtype-e.md)

<!--Device-userAuth-type AuthType = 'ALL' | 'FACE_ONLY'--><!--Device-userAuth-type AuthType = 'ALL' | 'FACE_ONLY'-End-->

**System capability:** SystemCapability.UserIAM.UserAuth.Core

| Type | Description |
| --- | --- |
| 'ALL' | Reserved parameter. Authentication of the **ALL** type is not supported in the current version. |
| 'FACE_ONLY' | Face authentication. |
