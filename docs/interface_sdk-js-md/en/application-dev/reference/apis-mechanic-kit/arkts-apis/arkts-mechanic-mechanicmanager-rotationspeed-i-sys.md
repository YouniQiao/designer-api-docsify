# RotationSpeed (System API)

Rotational speed. A negative value indicates a clockwise rotation, and a positive value indicates a counterclockwise rotation.

**Since:** 23

**ArkTS mode:** ArkTS-Dyn only, since version 23.

**Deprecated since:** -1
