# @ohos.application.abilityDelegatorRegistry

The **AbilityDelegatorRegistry** module provides APIs for storing global registers of the registered  
[AbilityDelegator]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_ and  
[AbilityDelegatorArgs]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_ objects, including obtaining the **AbilityDelegator** and **AbilityDelegatorArgs** objects. The APIs can be used only in the test framework.
