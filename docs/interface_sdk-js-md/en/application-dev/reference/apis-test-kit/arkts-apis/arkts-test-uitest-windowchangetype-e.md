# WindowChangeType

支持监听的窗口变化事件类型。

**Since:** 22

**ArkTS mode:** ArkTS-Dyn since version 22; ArkTS-Sta since version 23.

## WINDOW_UNDEFINED

```TypeScript
WINDOW_UNDEFINED = 0
```

非窗口变化事件。

**说明：** 该枚举值仅支持作为返回值，如果作为接口入参会抛出异常。

**Since:** 22

**ArkTS mode:** ArkTS-Dyn since version 22; ArkTS-Sta since version 23.

**Atomic service API:** This API can be used in atomic services since API version 22.
