# SymKey

Provides APIs for symmetric key operations. It is a child class of [Key](arkts-cryptoarchitecture-cryptoframework-key-i.md#Key).Its objects need to be passed to  
[init()](arkts-cryptoarchitecture-cryptoframework-cipher-i.md#init-3) of the  
[Cipher](arkts-cryptoarchitecture-cryptoframework-cipher-i.md#Cipher) instance in symmetric encryption and decryption.

&lt;br&gt;Symmetric keys can be generated by a [SymKeyGenerator](arkts-cryptoarchitecture-cryptoframework-symkeygenerator-i.md#SymKeyGenerator).

**Inheritance/Implementation:** SymKey extends [Key](arkts-cryptoarchitecture-cryptoframework-key-i.md#Key)

**Since:** 9

**ArkTS mode:** ArkTS-Dyn since version 9; ArkTS-Sta since version 23.

## clearMem

```TypeScript
clearMem(): void
```

Clears the key data in memory. This API returns the result synchronously. Call this API when the symmetric key instance is no longer required.

**Since:** 9

**ArkTS mode:** ArkTS-Dyn since version 9; ArkTS-Sta since version 23.

**Atomic service API:** This API can be used in atomic services since API version 12.

## Examples

```TypeScript
import { cryptoFramework } from '@kit.CryptoArchitectureKit';

async function testGenerateAesKeyFun() {
  let symKeyGenerator = cryptoFramework.createSymKeyGenerator('AES256');
  let key = await symKeyGenerator.generateSymKey();
  let encodedKey = key.getEncoded();
  console.info('key blob: '+ encodedKey.data);
  key.clearMem();
  encodedKey = key.getEncoded();
  console.info('key blob: ' + encodedKey.data);
}
```
