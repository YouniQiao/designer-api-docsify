# DataBlob

二进制数据的封装接口，核心字段data为Uint8Array类型。

> **说明：**
> 
> Uint8Array类型数据表示8位无符号整数的数组。

**Since:** 9

**ArkTS mode:** ArkTS-Dyn since version 9; ArkTS-Sta since version 23.
