# AudioRendererRate

Enumerates the audio renderer rates.

**Since:** 8

**ArkTS mode:** ArkTS-Dyn since version 8; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Multimedia.Audio.Renderer

```TypeScript

```

**System capability:** SystemCapability.Multimedia.Audio.Renderer
