# CaptureFilterOptions

Defines the options for filtering the played audio streams to be recorded.

**Since:** 10

**ArkTS mode:** ArkTS-Dyn only, since version 10.

**Deprecated since:** 12

**Substitutes:** OH_AVScreenCapture
