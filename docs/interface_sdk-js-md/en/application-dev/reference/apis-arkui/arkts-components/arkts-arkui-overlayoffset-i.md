# OverlayOffset

设置浮层基于自身左上角的偏移量。浮层默认处于组件左上角。

> **说明：**
> 
> 为规范匿名对象的定义，API 12版本修改了此处的元素定义。其中，保留了历史匿名对象的起始版本信息，会出现外层元素@since版本号高于内层元素版本号的情况，但这不影响接口的使用。

**Since:** 12

**ArkTS mode:** ArkTS-Dyn only, since version 12.
