# UIExtensionComponent properties/events

The [universal attributes](../../apis-ability-kit/arkts-apis/arkts-app-ability-common.md) are supported.

Universal events, such as the [click event](../../apis-ability-kit/arkts-apis/arkts-app-ability-common.md), are not supported.

The events are passed to the remote UIExtensionAbility for processing after coordinate conversion.
