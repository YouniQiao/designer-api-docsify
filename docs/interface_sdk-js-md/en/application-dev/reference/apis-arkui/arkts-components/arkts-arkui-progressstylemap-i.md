# ProgressStyleMap

Defines the mapping between progress indicators and styles.

**Since:** 10

**ArkTS mode:** ArkTS-Dyn only, since version 10.

## [ProgressType.Capsule]

```TypeScript
[ProgressType.Capsule]: CapsuleStyleOptions | ProgressStyleOptions
```

Progress bar style corresponding to the capsule progress bar.

**Type:** [CapsuleStyleOptions](arkts-arkui-capsulestyleoptions-i.md) \| [ProgressStyleOptions](arkts-arkui-progressstyleoptions-i.md)

**Since:** 10

**ArkTS mode:** ArkTS-Dyn only, since version 10.

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 11.
