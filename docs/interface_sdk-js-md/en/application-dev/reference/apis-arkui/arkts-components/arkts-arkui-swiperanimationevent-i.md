## currentOffset

```TypeScript
currentOffset: number
```

Swiper当前显示元素在主轴方向上，相对于Swiper起始位置的位移。单位VP，默认值为0。

**Type:** number

**Default:** 0.0 vp

**Since:** 10

**ArkTS mode:** ArkTS-Dyn only, since version 10.

**Model restriction:** This API can be used only in the stage model.
