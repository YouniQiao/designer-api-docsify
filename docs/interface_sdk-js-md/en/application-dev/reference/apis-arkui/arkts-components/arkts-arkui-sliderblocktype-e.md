# SliderBlockType

Slider组件滑块形状枚举。

| 名称 | 值 | 说明 |  
| ------- | -- | ---------------------- |  
| DEFAULT | 0 | 使用默认滑块（圆形）。 |  
| IMAGE | 1 | 使用图片资源作为滑块。 |  
| SHAPE | 2 | 使用自定义形状作为滑块。 |

**Since:** 10

**ArkTS mode:** ArkTS-Dyn only, since version 10.
