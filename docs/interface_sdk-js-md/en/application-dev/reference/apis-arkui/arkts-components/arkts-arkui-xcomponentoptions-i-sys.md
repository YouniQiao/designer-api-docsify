## screenId

```TypeScript
screenId?: number
```

给组件设置关联屏幕ID，通过此项可在组件上显示关联屏幕画面。屏幕ID可通过@ohos.screen.getAllScreens接口获取。&lt;br/&gt;默认值：**0**，表示主屏幕。

**Type:** number

**Since:** 17

**ArkTS mode:** ArkTS-Dyn only, since version 17.

**Model restriction:** This API can be used only in the stage model.
