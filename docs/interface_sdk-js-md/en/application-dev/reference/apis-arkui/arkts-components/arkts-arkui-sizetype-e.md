# SizeType

设备宽度类型枚举，用于在栅格布局中区分不同宽度的设备类型，实现响应式布局。

> **说明：**
> 
> 从API version 7开始支持，从API version 9开始废弃。

**Since:** 7

**ArkTS mode:** ArkTS-Dyn only, since version 7.

**Deprecated since:** 9

**Substitutes:** grid_col/GridColColumnOption
