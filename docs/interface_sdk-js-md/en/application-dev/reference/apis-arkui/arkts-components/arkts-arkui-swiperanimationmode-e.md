# SwiperAnimationMode

Swiper组件翻页至指定页面的动效模式。

**Since:** 15

**ArkTS mode:** ArkTS-Dyn only, since version 15.


**ArkTS mode:** ArkTS-Dyn only, since version 15.
