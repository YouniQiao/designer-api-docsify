# PointerStyle

```TypeScript
declare type PointerStyle = import('../api/@ohos.multimodalInput.pointer').default.PointerStyle
```

Defines the pointer style.
    **NOTE**  
    
    Directly using **cursorControl** can lead to the issue of  
    \_\_\_MD\_LINK\_DESC\_USD\_0\_\_\_. To avoid this, obtain the  
    [UIContext]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_ object using the **getUIContext()** API and then obtain the  
    **cursorControl** bound to the instance using the  
    [getCursorController]\_\_\_JSDOC\_LINK\_DESC\_USD\_2\_\_\_ API.

**Since:** 11

**ArkTS mode:** ArkTS-Dyn only, since version 11.

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 12.
