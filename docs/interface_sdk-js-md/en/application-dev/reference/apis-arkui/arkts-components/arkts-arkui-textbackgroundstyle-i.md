# TextBackgroundStyle

定义Span的背景样式。

**Since:** 11

**ArkTS mode:** ArkTS-Dyn only, since version 11.


文本背景色。默认为透明，无背景色。

**Type:** [ResourceColor](../arkts-apis/arkts-arkui-resourcecolor-t.md)

**ArkTS mode:** ArkTS-Dyn only, since version 11.
