# RemoteWindow

远程控制窗口组件，可以通过此组件控制应用窗口，提供启动退出过程中控件动画和应用窗口联动动画的能力。

## 子组件

不可以包含子组件

## RemoteWindow

```TypeScript
RemoteWindow(target: WindowAnimationTarget)
```

通过窗口动画对象创建组件。

**Since:** 9

**ArkTS mode:** ArkTS-Dyn only, since version 9.
