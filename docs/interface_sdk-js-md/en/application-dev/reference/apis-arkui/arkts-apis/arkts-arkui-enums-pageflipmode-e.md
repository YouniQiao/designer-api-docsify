# PageFlipMode

Page flip mode of Swiper and Tabs on mouse wheel event.@enum { number } PageFlipMode

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## CONTINUOUS

```TypeScript
CONTINUOUS = 0
```

Turn pages continuously according to the number of mouse wheel events.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## SINGLE

```TypeScript
SINGLE = 1
```

The page-turning animation remains unresponsive to other mouse wheel events until it completes.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full
