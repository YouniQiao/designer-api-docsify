# setCursor

## setCursor

```TypeScript
function setCursor(value: PointerStyle): void
```

Change the mouse cursor style by param: 'PointerStyle'.

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
