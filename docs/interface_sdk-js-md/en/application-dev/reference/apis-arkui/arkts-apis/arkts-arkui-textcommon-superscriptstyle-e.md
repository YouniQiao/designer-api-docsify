# SuperscriptStyle

Defines the superscript style.

**Since:** 24

**ArkTS mode:** Supports only ArkTS-Sta, since version 24.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## NORMAL

```TypeScript
NORMAL = 0
```

normal font style.

**Since:** 24

**ArkTS mode:** Supports only ArkTS-Sta, since version 24.
