| [HalfScreenLaunchComponent](arkts-arkui-atomicservicehalfscreenlaunchcomponent-halfscreenlaunchcomponent-s.md) | *HalfScreenLaunchComponent** is a component designed for launching atomic services in half screen. If the invoked application (the one being launched) grants the invoker the authorization to run the atomic service in an embedded manner, the invoker can operate the atomic service in half-screen embedded mode. If authorization is not provided, the invoker will launch the atomic service in a pop-up manner. |
