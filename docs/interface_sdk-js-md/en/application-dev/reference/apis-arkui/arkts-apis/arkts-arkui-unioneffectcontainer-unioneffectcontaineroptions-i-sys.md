## spacing

```TypeScript
spacing?: double
```

Spacing indicates the ease with which fusion occurs; it does not represent actual distance. The larger the spacing, the easier it is for subcomponents to fuse, and the greater the degree of fusion. Value constraint: Must be greater than or equal to 0.

**Type:** double

**Default:** 0

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.
