# ChainWeightOptions

链中组件的布局权重。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

## horizontal

```TypeScript
horizontal?: double
```

组件在水平方向的布局权重，设置大于0的数字时生效。 

默认值：0 

异常值：0

**Type:** double

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
