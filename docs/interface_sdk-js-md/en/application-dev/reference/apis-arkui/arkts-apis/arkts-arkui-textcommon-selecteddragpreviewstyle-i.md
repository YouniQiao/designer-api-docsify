## color

```TypeScript
color?: ResourceColor
```

用于设置文本拖拽时的背板颜色。

默认值：跟随主题。默认主题时，浅色模式显示白色，深色模式显示黑色。

**Type:** [ResourceColor](arkts-arkui-resourcecolor-t.md)

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
