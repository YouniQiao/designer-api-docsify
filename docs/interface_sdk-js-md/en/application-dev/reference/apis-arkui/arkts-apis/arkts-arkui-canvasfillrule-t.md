# CanvasFillRule

```TypeScript
export type CanvasFillRule = 'evenodd' | 'nonzero'
```

Filling style algorithm, which determines whether a point is within or outside the path. The following  two configurations are supported:'evenodd': odd and even round rule'nonzero': (Default) Non-zero Wrap Rules

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
