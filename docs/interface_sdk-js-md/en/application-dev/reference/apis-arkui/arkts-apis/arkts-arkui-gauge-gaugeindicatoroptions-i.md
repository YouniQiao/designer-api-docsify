# GaugeIndicatorOptions

Defines the options of gauge indicator.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## icon

```TypeScript
icon?: ResourceStr
```

Current indicator icon path.

**Type:** [ResourceStr](arkts-arkui-resourcestr-t.md)

**Default:** system style.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## space

```TypeScript
space?: Dimension
```

Current indicator space. Default value: 8vp. <br>**Note: * * For the default triangle style pointer, the spacing is the distance from the black triangle to the outer edge of the ring.

**Type:** [Dimension](arkts-arkui-dimension-t.md)

**Default:** 8vp

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full
