# StorageLink

Defining StorageLink annotation StorageLink is used to create a two-way data synchronization between the variable it decorates and the attribute with the given key in AppStorage.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

property: string

The give property in AppStorage.
