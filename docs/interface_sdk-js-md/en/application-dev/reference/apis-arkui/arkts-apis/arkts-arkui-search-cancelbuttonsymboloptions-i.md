# CancelButtonSymbolOptions

Defines the CancelButton symbol options

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## icon

```TypeScript
icon?: SymbolGlyphModifier
```

Set the CancelButton symbol icon. Symbol icon of the Cancel button on the right.

**Type:** [SymbolGlyphModifier](arkts-arkui-symbolglyphmodifier-c.md)

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## style

```TypeScript
style?: CancelButtonStyle
```

Set the CancelButton style. Display state of the Cancel button on the right.

**Type:** [CancelButtonStyle](arkts-arkui-search-cancelbuttonstyle-e.md)

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full
