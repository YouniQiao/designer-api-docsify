```TypeScript

```

## startX

```TypeScript
startX: long
```

屏幕的起始X轴坐标。以两块屏幕外接矩形的左上顶点为原点，向右为正方向。该参数应为正整数，非正整数会作为非法参数报错。

**Type:** ArkTS-Dyn: number  <br>ArkTS-Sta：long

**Since:** 13

**ArkTS mode:** ArkTS-Dyn since version 13; ArkTS-Sta since version 23.
