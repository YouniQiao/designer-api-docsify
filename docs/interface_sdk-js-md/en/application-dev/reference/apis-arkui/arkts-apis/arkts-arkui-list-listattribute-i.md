## maintainVisibleContentPosition

```TypeScript
default maintainVisibleContentPosition(enabled: boolean | undefined): this
```

Sets whether the visible content position should remain unchanged when data is inserted or deleted above the visible area.<p>&lt;strong&gt;NOTE&lt;/strong&gt;: <br>- The visible content position will only remain unchanged when &lt;em&gt;LazyForEach&lt;/em&gt; is used to insert or delete data outside the visible area.If &lt;em&gt;ForEach&lt;/em&gt; is used to insert or delete data, or if &lt;em&gt;LazyForEach&lt;/em&gt; is used for data reloading, the visible content position will change even if &lt;em&gt;maintainVisibleContentPosition&lt;/em&gt; is set to &lt;em&gt;true&lt;/em&gt;. <br>- When &lt;em&gt;maintainVisibleContentPosition&lt;/em&gt; is set to &lt;em&gt;true&lt;/em&gt;, inserting or deleting data above the visible area will trigger &lt;em&gt;onDidScroll&lt;/em&gt; and &lt;em&gt;onScrollIndex&lt;/em&gt; events. <br>- In a multi-column scenario, setting &lt;em&gt;maintainVisibleContentPosition&lt;/em&gt; to &lt;em&gt;true&lt;/em&gt; allows you to insert or delete entire rows of data while keeping the visible content position unchanged. If the insertion or deletion does not involve entire rows, however, the visible content position will still change. </p>
