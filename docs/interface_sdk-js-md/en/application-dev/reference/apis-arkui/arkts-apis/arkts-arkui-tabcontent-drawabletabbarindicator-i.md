# DrawableTabBarIndicator

Provide an interface for the style of a drawable indicator including margin top.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## borderRadius

```TypeScript
borderRadius?: Length
```

Rounded corner radius of the indicator. It cannot be set in percentage. <br>Value constraint:[0, +∞). <br>Default value:0.0vp.

**Type:** [Length](arkts-arkui-length-t.md)

**Default:** 0

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 23.

**System capability:** SystemCapability.ArkUI.ArkUI.Full
