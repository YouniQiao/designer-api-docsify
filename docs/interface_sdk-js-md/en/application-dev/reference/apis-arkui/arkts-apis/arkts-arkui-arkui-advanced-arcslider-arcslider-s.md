# ArcSlider

The **ArcSlider** component is designed for circular screens on wearables to quickly adjust settings, such as the volume and brightness. > **NOTE：**

**Since:** 18

**ArkTS mode:** ArkTS-Dyn only, since version 18.

**Deprecated since:** -1
