## DEFAULT

```TypeScript
DEFAULT = 0
```

交叉轴方向键不允许换行。

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Sta only, since version 26.0.0.

## WRAP_WITH_ARROW

```TypeScript
WRAP_WITH_ARROW = 1
```

交叉轴方向键允许换行。

不规则单元格场景下，交叉轴方向键走焦时优先走到同一行的可获焦item。

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Sta only, since version 26.0.0.

**Model restriction:** This API can be used only in the stage model.
