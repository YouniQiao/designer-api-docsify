# PathOptions

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

## commands

```TypeScript
commands?: ResourceStr
```

路径绘制的命令字符串。

默认值：空字符串

异常值按照默认值处理。

**Type:** [ResourceStr](arkts-arkui-resourcestr-t.md)

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.

