# UrlStyle

超链接对象说明。

默认颜色、字号、字重分别是'#ff0a59f7'、'16fp'、'FontWeight.Regular'，若属性字符串设置TextStyle，则TextStyle优先级更高。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.
