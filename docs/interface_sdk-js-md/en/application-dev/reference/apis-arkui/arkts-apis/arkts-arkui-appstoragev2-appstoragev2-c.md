# AppStorageV2

AppStorageV2 is for UI state of app-wide access, has same life cycle as the app,and saves database content only in memory.

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Sta only, since version 26.0.0.

## connect

```TypeScript
public static connect<T extends object>(ttype: Class, key: string,
    defaultCreator?: StorageDefaultCreator<T>): T | undefined
```

If the value for the given key is already available, return the value.If not, add the key with value generated by calling defaultFunc and return it to caller.

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Sta only, since version 26.0.0.

**Model restriction:** This API can be used only in the stage model.
