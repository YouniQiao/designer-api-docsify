## dashGap

```TypeScript
dashGap?: EdgeWidths | LengthMetrics | LocalizedEdgeWidths
```

不支持设置百分比。

**Type:** [EdgeWidths](arkts-arkui-units-edgewidths-i.md) \| LengthMetrics \| LocalizedEdgeWidths

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.
