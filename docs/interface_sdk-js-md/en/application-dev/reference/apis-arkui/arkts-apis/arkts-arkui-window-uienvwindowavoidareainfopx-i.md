# UIEnvWindowAvoidAreaInfoPX

Describes \_\_\_MD\_LINK\_DESC\_USD\_0\_\_\_ data types for window avoidance areas of different types. All types of window avoidance areas are measured in px.

**Since:** 23

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 23.
