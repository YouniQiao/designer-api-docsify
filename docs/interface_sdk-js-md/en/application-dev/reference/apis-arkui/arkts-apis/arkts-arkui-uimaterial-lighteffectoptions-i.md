# LightEffectOptions

沉浸式材质的光感交互反馈配置。用于自定义反馈光感的颜色。

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Sta only, since version 26.0.0.

## color

```TypeScript
color?: ResourceColor
```

自定义交互反馈光感的颜色。

默认值：Color.White

**Type:** [ResourceColor](arkts-arkui-resourcecolor-t.md)

**Default:** Color.White

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Sta only, since version 26.0.0.

**Model restriction:** This API can be used only in the stage model.
