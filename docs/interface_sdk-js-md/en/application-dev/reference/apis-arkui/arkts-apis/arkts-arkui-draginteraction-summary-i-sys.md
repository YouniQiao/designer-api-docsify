# Summary (System API)

Defines the data summary of the dragged object.

**Since:** 11

**ArkTS mode:** ArkTS-Dyn since version 11; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Msdp.DeviceStatus.Drag

**System API:** This is a system API.
