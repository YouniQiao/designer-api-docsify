## borderRadius

```TypeScript
borderRadius?: Length
```

背板的圆角半径（不支持百分比设置）。

默认值：8.0

单位：vp

取值范围：[0, +∞)。

**Type:** [Length](arkts-arkui-length-t.md)

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
