# IconStyle

设置关闭按钮的色调样式，默认为亮色调。

| 名称 | 值 | 说明 |  
| - | - | - |  
| DARK | 0 | 设置关闭按钮为暗色调。 |  
| LIGHT | 1 | 设置关闭按钮为亮色调。默认值。 |

**Since:** 12

**ArkTS mode:** ArkTS-Dyn only, since version 12.
