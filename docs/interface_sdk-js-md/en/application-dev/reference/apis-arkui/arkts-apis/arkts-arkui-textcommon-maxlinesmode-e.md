# MaxLinesMode

TextArea组件在文本超长时显示效果。默认值为CLIP，按最大行截断显示。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## CLIP

```TypeScript
CLIP = 0
```

文本超长时按最大行截断显示。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
