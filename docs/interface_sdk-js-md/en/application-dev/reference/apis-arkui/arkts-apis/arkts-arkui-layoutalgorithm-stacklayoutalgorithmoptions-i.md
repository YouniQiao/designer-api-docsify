## alignContent

```TypeScript
alignContent?: LocalizedAlignment
```

设置子组件在堆叠布局算法中对齐格式。非法值：按默认值处理。

**Type:** [LocalizedAlignment](arkts-arkui-enums-localizedalignment-e.md)

**Default:** LocalizedAlignment.Center

**Since:** 24

**ArkTS mode:** ArkTS-Sta only, since version 24.
