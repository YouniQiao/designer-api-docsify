# EdgeWidths

type EdgeWidths = { top: Length; right: Length; bottom: Length; left: Length; }

边框宽度类型，用于描述组件边框不同方向的宽度。

引入该对象时，至少传入一个参数。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.
