## stopWhenTouched

```TypeScript
stopWhenTouched: boolean
```

在按下事件中配置子组件是否立即停止播放。

true表示停止播放；false表示自动播放不中断。

默认值：true

**Type:** boolean

**Default:** true

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
