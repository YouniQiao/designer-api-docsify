# ButtonStyle

设置侧边栏控制按钮的样式。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

<!--Device-unnamed-export declare interface ButtonStyle--><!--Device-unnamed-export declare interface ButtonStyle-End-->

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## height

```TypeScript
height?: double
```

设置侧边栏控制按钮的高度。

默认值：

API version 9及之前版本：32vp

从API version 10开始：24vp

单位：vp

取值范围：[0, +∞)

异常值时取默认值。

**Type:** double

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.

<!--Device-ButtonStyle-height?: double--><!--Device-ButtonStyle-height?: double-End-->

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## icons

```TypeScript
icons?: ButtonIconOptions
```

设置侧边栏控制按钮的图标。

资源获取错误以及未设置该属性时，使用默认图标。

**Type:** [ButtonIconOptions](../arkts-components/arkts-arkui-buttoniconoptions-i.md)

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
