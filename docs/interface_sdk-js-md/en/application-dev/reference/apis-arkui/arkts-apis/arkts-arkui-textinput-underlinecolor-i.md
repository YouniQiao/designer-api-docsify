# UnderlineColor

Defines the underline color width property.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## disable

```TypeScript
disable?: ResourceColor | undefined
```

Disable underline color width property. <p>&lt;strong&gt;NOTE&lt;/strong&gt;: <br>If no value is specified or if the value specified is undefined, null, or invalid, the default value is used. </p>

**Type:** [ResourceColor](arkts-arkui-resourcecolor-t.md) \| undefined

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## error

```TypeScript
error?: ResourceColor | undefined
```

Error underline color width property. <p>&lt;strong&gt;NOTE&lt;/strong&gt;: <br>If no value is specified or if the value specified is undefined, null, or invalid, the default value is used. <br>This option changes the color used in the showCounter attribute when the maximum number of characters is reached. </p>

**Type:** [ResourceColor](arkts-arkui-resourcecolor-t.md) \| undefined

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full
