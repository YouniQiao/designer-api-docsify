# StateStyles

Component State Styles.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## clicked

```TypeScript
clicked?: CustomStyles
```

Defines clicked state styles.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.
