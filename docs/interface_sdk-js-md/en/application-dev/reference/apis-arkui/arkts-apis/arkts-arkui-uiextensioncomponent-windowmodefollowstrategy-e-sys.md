# WindowModeFollowStrategy (System API)

窗口Mode跟随策略，用于设置窗口Mode，使其能够跟随宿主或UIExtensionAbility。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

<!--Device-unnamed-export declare enum WindowModeFollowStrategy--><!--Device-unnamed-export declare enum WindowModeFollowStrategy-End-->

**System capability:** SystemCapability.ArkUI.ArkUI.Full

**System API:** This is a system API.

## FOLLOW_HOST_WINDOW_MODE

```TypeScript
FOLLOW_HOST_WINDOW_MODE = 0
```

表示窗口Mode跟随宿主。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.

<!--Device-WindowModeFollowStrategy-FOLLOW_HOST_WINDOW_MODE = 0--><!--Device-WindowModeFollowStrategy-FOLLOW_HOST_WINDOW_MODE = 0-End-->

**System capability:** SystemCapability.ArkUI.ArkUI.Full

**System API:** This is a system API.

```TypeScript
FOLLOW_UI_EXTENSION_ABILITY_WINDOW_MODE = 1
```

表示窗口Mode跟随UIExtensionAbility。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
