# Entry

Defines Entry Annotation.Entry is an Annotation and it supports parameters.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## routeName

```TypeScript
routeName: string = ""
```

Named route name.

**Type:** string

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## storage

```TypeScript
storage: string = ""
```

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

## useSharedStorage

```TypeScript
useSharedStorage: boolean = false
```

Determines whether to use the LocalStorage instance object returned by UIContext.getSharedLocalStorage() interface.

**Type:** boolean

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.
