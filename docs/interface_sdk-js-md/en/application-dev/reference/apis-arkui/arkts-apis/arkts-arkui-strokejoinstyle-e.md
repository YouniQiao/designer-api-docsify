# StrokeJoinStyle

```TypeScript
declare enum StrokeJoinStyle
```

Defines the style of line corners, that is, the brush style at the corners of line segments when drawing polylines.

**Since:** 26.0.0

**System capability:** SystemCapability.ArkUI.ArkUI.Full
