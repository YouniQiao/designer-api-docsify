**ArkTS mode:** ArkTS-Dyn since version 7; ArkTS-Sta since version 23.

## PRIMARY

```TypeScript
PRIMARY = 3
```

表示APP分屏多窗口主要模式。上下分屏时，上分屏为主要模式。左右分屏时，左分屏为主要模式。

**Since:** 7
