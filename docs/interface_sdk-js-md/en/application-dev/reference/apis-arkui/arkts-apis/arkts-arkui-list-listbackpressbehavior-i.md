## closeSwipeAction

```TypeScript
closeSwipeAction?: boolean
```

系统返回键生效时，是否收起已展开的ListItem的划出组件。

**Type:** boolean

**Default:** true

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Sta only, since version 26.0.0.

**Model restriction:** This API can be used only in the stage model.
