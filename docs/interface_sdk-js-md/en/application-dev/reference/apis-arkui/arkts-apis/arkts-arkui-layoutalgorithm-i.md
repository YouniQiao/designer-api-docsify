# LayoutAlgorithm

DynamicLayout组件支持的布局算法基础类型。

> **说明：**
> 
> 该类型变量可以赋值具体的布局算法类对象，
> 如[CustomLayoutAlgorithm](#customlayoutalgorithm)类对象、
> [RowLayoutAlgorithm](#rowlayoutalgorithm)类对象等。

**Since:** 24

**ArkTS mode:** ArkTS-Sta only, since version 24.
