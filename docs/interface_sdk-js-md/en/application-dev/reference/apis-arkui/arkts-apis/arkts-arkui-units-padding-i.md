# Padding

type Padding = { top: Length; right: Length; bottom: Length; left: Length; }

内边距类型，用于描述组件不同方向的内边距。

引入该对象时，至少传入一个参数。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.
