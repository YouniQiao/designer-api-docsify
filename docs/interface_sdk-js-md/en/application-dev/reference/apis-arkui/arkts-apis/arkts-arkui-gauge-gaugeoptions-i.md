# GaugeOptions

Defines Gauge constructor options.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## max

```TypeScript
max?: double
```

Set current segment maximum value. Anonymous Object Rectification. Default value: 100. <br>**Note: * * If max is less than min, the default values 0 and 100 are used.

**Type:** double

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## min

```TypeScript
min?: double
```

Set current segment minimum value. Anonymous Object Rectification. Default value: 0.

**Type:** double

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## value

value: double | undefined
