# MenuGridStyleOptions

Defines grid style of menu.

**Since:** 26.0.0

**ArkTS mode:** Supports only ArkTS-Sta, since version 26.0.0.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## count

```TypeScript
count?: int
```

The count of items in grid.

**Type:** int

**Default:** 3

**Since:** 26.0.0

**ArkTS mode:** Supports only ArkTS-Sta, since version 26.0.0.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## horizontalSize

```TypeScript
horizontalSize?: int
```

The horizontal size of items in grid.

**Type:** int

**Default:** 3

**Since:** 26.0.0

**ArkTS mode:** Supports only ArkTS-Sta, since version 26.0.0.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## position

```TypeScript
position?: MenuGridPosition
```

The position of grid.

**Type:** [MenuGridPosition](arkts-arkui-common-menugridposition-e.md)

**Default:** MenuGridPosition.TOP

**Since:** 26.0.0

**ArkTS mode:** Supports only ArkTS-Sta, since version 26.0.0.

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.ArkUI.ArkUI.Full
