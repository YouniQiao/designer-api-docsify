# SelectionContainerTextJoinStyle

文本聚合拼接方式。

| 名称 | 值 | 说明 |  
| ---- | -- | ---- |  
| NEWLINE | 0 | 不同文本节点之间使用换行符`\n`拼接。 |  
| DIRECT | 1 | 不同文本节点之间直接拼接，不添加分隔符。 |

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Sta only, since version 26.0.0.
