# TextChangeReason (System API)

Defines the reason for text changes.

**Since:** 24

**ArkTS mode:** Supports only ArkTS-Sta, since version 24.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

**System API:** This is a system API.

## UNKNOWN

```TypeScript
UNKNOWN = 0
```

Default value.
