# ActionSheetOffset

弹窗的对齐方式。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

<!--Device-unnamed-export interface ActionSheetOffset--><!--Device-unnamed-export interface ActionSheetOffset-End-->

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## dx

```TypeScript
dx: double | string | Resource
```

弹出窗口相对于对齐位置dx的偏移量。

需要显式指定像素单位，如'10px'，也可设置百分比字符串，如'100%'。

**说明：**

不指定像素单位时，默认单位vp，如'10'，等同于10。

**Type:** double \| string \| Resource

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
