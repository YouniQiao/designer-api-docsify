# SheetSize

Defines sheet size type.

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

## MEDIUM

```TypeScript
MEDIUM = 0
```

The sheet height is half of the screen height.

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
