# LocalizedBarrierDirection

定义支持镜像模式的屏障线的方向。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

## START

```TypeScript
START = 0
```

屏障在其所有referencedId的最左/右侧，LTR模式时为最左侧，RTL模式时为最右侧。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
