# DatePickerComponent

DatePickerComponent组件用于选择日期（年月日）和时间（时分秒）。

> **说明：**
> 
> - 该组件接口仅可在Stage模型下使用。

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Sta only, since version 26.0.0.

**Decorator:** @Component
