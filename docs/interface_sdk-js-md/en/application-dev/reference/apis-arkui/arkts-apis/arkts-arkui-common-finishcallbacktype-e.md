# FinishCallbackType

动画中定义onFinish回调的类型。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

## REMOVED

```TypeScript
REMOVED = 0
```

当整个动画结束并立即删除时，将触发回调。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.

## LOGICALLY

```TypeScript
LOGICALLY = 1
```

当动画在逻辑上处于下降状态，但可能仍处于其长尾状态时，将触发回调。

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
