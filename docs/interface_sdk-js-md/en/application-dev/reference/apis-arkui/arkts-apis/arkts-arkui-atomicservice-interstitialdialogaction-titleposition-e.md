# TitlePosition

设置主副标题之间的上下相对位置，默认设置为主标题在副标题之上。

| 名称 | 值 | 说明 |  
| - | - | - |  
| TOP | 0 | 设置主标题位于副标题之上。默认值。 |  
| BOTTOM | 1 | 设置主标题位于副标题之下。 |

**Since:** 12

**ArkTS mode:** ArkTS-Dyn only, since version 12.
