## alwaysRender

```TypeScript
alwaysRender?: boolean
```

如果为true，即使场景没有变化也始终渲染自上一帧以来. 如果为false，则场景没有变化时可以省略渲染.

**Type:** boolean

**Since:** 15

**ArkTS mode:** ArkTS-Dyn since version 15; ArkTS-Sta since version 23.
