## consumeKeyEvents

```TypeScript
consumeKeyEvents?: boolean
```

Whether the editor supports consuming key events.

**Type:** boolean

**Default:** false

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 26.0.0.
