# CapitalizeMode

枚举，定义了文本首字母大写的不同模式。

| 名称 | 值 | 说明 |  
| -------- | -- | -------- |  
| NONE | 0 | 不进行任何首字母大写处理。|  
| SENTENCES | 1 | 每个句子的首字母大写。|  
| WORDS | 2 | 每个单词的首字母大写。|  
| CHARACTERS | 3 | 每个字母都大写。|

**Since:** 20

**ArkTS mode:** ArkTS-Dyn since version 20; ArkTS-Sta since version 23.
