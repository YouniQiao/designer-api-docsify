# Direction

**Since:** 10

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.

## CURSOR_UP

```TypeScript
CURSOR_UP = 1
```

向上。

**使用场景：**输入法请求光标向上移动时使用，如多行文本中上移光标。

**Since:** 10

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.
