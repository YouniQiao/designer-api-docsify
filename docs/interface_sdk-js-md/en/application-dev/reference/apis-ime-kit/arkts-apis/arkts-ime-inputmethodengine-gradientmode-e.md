# GradientMode

枚举，输入法渐变模式。

| 名称 | 值 | 说明 |  
| ------------ | -- | ------------------ |  
| NONE | 0 | 不使用渐变模式。 |  
| LINEAR_GRADIENT | 1 | 线性渐变。 |

**Since:** 20

**ArkTS mode:** ArkTS-Dyn since version 20; ArkTS-Sta since version 23.
