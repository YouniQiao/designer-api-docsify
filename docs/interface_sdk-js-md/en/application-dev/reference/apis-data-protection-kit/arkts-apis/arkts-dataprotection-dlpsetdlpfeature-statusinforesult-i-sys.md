## isSuccess

```TypeScript
isSuccess: boolean
```

DLP特性开关状态是否设置成功。true表示设置成功；false表示设置失败。

**Type:** boolean

**Since:** 26.0.0

**ArkTS mode:** ArkTS-Dyn only, since version 26.0.0.

**Model restriction:** This API can be used only in the stage model.
