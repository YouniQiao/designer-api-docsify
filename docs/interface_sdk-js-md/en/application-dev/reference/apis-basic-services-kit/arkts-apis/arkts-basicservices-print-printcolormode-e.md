# PrintColorMode

Enumerates the color modes.

**Since:** 11

**ArkTS mode:** ArkTS-Dyn since version 11; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Print.PrintFramework

## COLOR_MODE_MONOCHROME

```TypeScript
COLOR_MODE_MONOCHROME = 0
```

Black and white.

**Since:** 11

**ArkTS mode:** ArkTS-Dyn since version 11; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Print.PrintFramework

## COLOR_MODE_COLOR

```TypeScript
COLOR_MODE_COLOR = 1
```

Color.

**Since:** 11

**ArkTS mode:** ArkTS-Dyn since version 11; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Print.PrintFramework
