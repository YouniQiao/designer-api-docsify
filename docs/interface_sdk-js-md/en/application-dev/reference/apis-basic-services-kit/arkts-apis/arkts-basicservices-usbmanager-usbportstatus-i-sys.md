# USBPortStatus (System API)

Enumerates USB port roles.

**Since:** 9

**ArkTS mode:** ArkTS-Dyn since version 9; ArkTS-Sta since version 23.

**System capability:** SystemCapability.USB.USBManager

**System API:** This is a system API.
