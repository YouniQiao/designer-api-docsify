# @ohos.annotation(Annotation)

This module defines the annotation types of OpenHarmony ArkTS APIs, such as the minimum available version
 of the lifecycle and suppressing warnings generated by APIs.
 It helps developers identify and manage API features such as compatibility and warning suppression.
 This module addresses issues such as version compatibility warnings, permission warnings,
 and multi-device adaptation warnings encountered during cross-version development
 and third-party SDK integration.
 Annotations are used to suppress unnecessary warnings, improving code maintainability
 and development efficiency.
 > **NOTE**
 >
 > - The initial APIs of this module are supported since API version 22.
 >   Newly added APIs will be marked with a superscript to indicate their earliest API version.
