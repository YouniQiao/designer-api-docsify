# SelectionType

Enumerates the word selection types.  
| [Name](../../apis-contacts-kit/arkts-apis/arkts-contacts-contact-name-c.md) | [Value](../../apis-arkdata/arkts-apis/arkts-arkdata-distributeddata-value-i.md) | Description | | ------------ | -- | ------------------ | | [MOUSE_MOVE](arkts-basicservices-selectionmanager-selectiontype-e.md) | 1 | Word selection by sliding the mouse or touchpad. | | [DOUBLE_CLICK](#double_click) | 2 | Word selection by double-clicking the mouse or touchpad. | | [TRIPLE_CLICK](arkts-basicservices-selectionmanager-selectiontype-e.md) | 3 |

**Since:** 24

**ArkTS mode:** ArkTS-Dyn since version 20; ArkTS-Sta since version 24.

**System capability:** SystemCapability.SelectionInput.Selection

## MOUSE_MOVE

