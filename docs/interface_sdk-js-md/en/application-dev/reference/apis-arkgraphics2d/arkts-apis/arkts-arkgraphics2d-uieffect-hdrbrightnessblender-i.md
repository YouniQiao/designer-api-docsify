# HdrBrightnessBlender (System API)

支持HDR的提亮混合器（继承自BrightnessBlender），用于将提亮效果添加到指定的组件上。在调用HdrBrightnessBlender前，需要先通过createHdrBrightnessBlender创建一个HdrBrightnessBlender实例。该混合器参数可参考BrightnessBlender。

**Inheritance/Implementation:** HdrBrightnessBlender extends [BrightnessBlender](arkts-arkgraphics2d-uieffect-brightnessblender-i-sys.md)

**Since:** 20

**ArkTS mode:** ArkTS-Dyn since version 20; ArkTS-Sta since version 23.
