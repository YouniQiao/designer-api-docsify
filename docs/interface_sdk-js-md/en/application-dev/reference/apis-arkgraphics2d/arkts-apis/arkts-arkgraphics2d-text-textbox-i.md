# TextBox

文本矩形区域，表示文本在布局时所占用的矩形空间。

**Since:** 12

**ArkTS mode:** ArkTS-Dyn since version 12; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Graphics.Drawing
