# WebHandednessFollowMode

```TypeScript
declare enum WebHandednessFollowMode
```

Defines the grip adaptation mode of the web page pop-up box.

**Since:** 26.1.0

<!--Device-unnamed-declare enum WebHandednessFollowMode--><!--Device-unnamed-declare enum WebHandednessFollowMode-End-->

**System capability:** SystemCapability.Web.Webview.Core

## FOLLOW_ANCHOR

```TypeScript
FOLLOW_ANCHOR = 1
```

The pop-up box follows the position of the component that triggers it (the most recently interacted component).

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.

<!--Device-WebHandednessFollowMode-FOLLOW_ANCHOR = 1--><!--Device-WebHandednessFollowMode-FOLLOW_ANCHOR = 1-End-->

**System capability:** SystemCapability.Web.Webview.Core

## NONE

```TypeScript
NONE = 0
```

No adaptation. The pop-up box keeps the current layout.

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.

<!--Device-WebHandednessFollowMode-NONE = 0--><!--Device-WebHandednessFollowMode-NONE = 0-End-->

**System capability:** SystemCapability.Web.Webview.Core
