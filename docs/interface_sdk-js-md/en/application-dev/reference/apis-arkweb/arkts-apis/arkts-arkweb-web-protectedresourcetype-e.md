# ProtectedResourceType

Defines the accessible resource type, related to [onPermissionRequest](arkts-arkweb-web-webattribute-i.md#onpermissionrequest) method.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.Web.Webview.Core

## MIDI_SYSEX

```TypeScript
MIDI_SYSEX = 'TYPE_MIDI_SYSEX'
```

The MidiSysex resource. Currently, only permission events can be reported. MIDI devices are not yet supported.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.Web.Webview.Core
