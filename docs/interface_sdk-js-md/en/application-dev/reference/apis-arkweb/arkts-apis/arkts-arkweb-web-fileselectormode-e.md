# FileSelectorMode

Enum type supplied to [FileSelectorParam](arkts-arkweb-web-fileselectorparam-c.md) when onFileSelectorShow being called.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.Web.Webview.Core

## FILE_OPEN_MODE

```TypeScript
FILE_OPEN_MODE = 0
```

Open and upload a file.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.Web.Webview.Core
