# WebRotateEffect

Enum type supplied to [rotateRenderEffect](arkts-arkweb-web-webattribute-i.md#rotaterendereffect) for setting the effect of rotation.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.Web.Webview.Core

## TOPLEFT_EFFECT

```TypeScript
TOPLEFT_EFFECT = 0
```

The content area is drawn in top-left of the node.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.Web.Webview.Core

## RESIZE_COVER_EFFECT

```TypeScript
RESIZE_COVER_EFFECT = 1
```

Scale the content area to cover the node.

**Since:** 23

**ArkTS mode:** Supports only ArkTS-Sta, since version 23.

**System capability:** SystemCapability.Web.Webview.Core
