Defines the viewport-fit type, related to [ViewportFit](#ViewportFit).

## AUTO

```TypeScript
AUTO = 0
```

No effect - the whole web page is viewable(default)

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

## CONTAINS

```TypeScript
CONTAINS = 1
```

The initial layout viewport and the visual viewport are set to the largest rectangle which is inscribe in the display of the device.

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

<!--Device-ViewportFit-CONTAINS = 1--><!--Device-ViewportFit-CONTAINS = 1-End-->

**System capability:** SystemCapability.Web.Webview.Core

## COVER

```TypeScript
COVER = 2
```

The initial layout viewport and the visual viewport are set to the circumscribe rectangle of the physical screen of the device.

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.
