# OnReleaseCallback

```TypeScript
export type OnReleaseCallback = (msg: string) => void
```

Defines the callback that is invoked when the stub on the target UIAbility is disconnected.

**Since:** 23

**Model restriction:** This API can be used only in the stage model.
