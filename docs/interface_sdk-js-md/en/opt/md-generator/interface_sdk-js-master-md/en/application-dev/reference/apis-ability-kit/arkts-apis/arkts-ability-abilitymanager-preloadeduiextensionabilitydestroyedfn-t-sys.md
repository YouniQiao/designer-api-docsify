# PreloadedUIExtensionAbilityDestroyedFn (System API)

```TypeScript
export type PreloadedUIExtensionAbilityDestroyedFn = (preloadId: number) => void
```

[UIExtensionAbility](arkts-ability-app-ability-uiextensionability-uiextensionability-c.md) instance is destroyed.

**Since:** 23

**Model restriction:** This API can be used only in the stage model.
