# IconStyle

Sets the color style of the close button. By default, the close button is set to light color.

| [Name](../../apis-contacts-kit/arkts-apis/arkts-contacts-contact-name-c.md) | [Value](../../apis-arkdata/arkts-apis/arkts-arkdata-distributeddata-value-i.md) | Description|
| - | - | - |
| [DARK](#dark) | 0 | The close button is in dark color.|
| [LIGHT](#light) | 1 |

**Since:** 12
