# TitlePosition

Defines the vertical position of the title relative to the subtitle in the dialog box. By default, the title is above the subtitle.

| [Name](../../apis-contacts-kit/arkts-apis/arkts-contacts-contact-name-c.md) | [Value](../../apis-arkdata/arkts-apis/arkts-arkdata-distributeddata-value-i.md) | Description|
| - | - | - |
| [TOP](#top) | 0 | The title is above the subtitle.Default value.|
| [BOTTOM](#bottom) | 1 |

**Since:** 12

## TOP

```TypeScript
TOP = 0
```

The main title is above the text content.

**Since:** 12

**Atomic service API:** This API can be used in atomic services since API version 12.
