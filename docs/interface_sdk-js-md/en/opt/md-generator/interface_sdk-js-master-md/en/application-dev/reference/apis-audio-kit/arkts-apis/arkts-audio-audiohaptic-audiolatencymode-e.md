## AUDIO_LATENCY_MODE_FAST

```TypeScript
AUDIO_LATENCY_MODE_FAST = 1
```

Low latency mode. This mode is applicable to short audio files. A long audio file may be truncated in this mode. It functions the same as SoundPool.

**Since:** 23
