## focusOnShow

```TypeScript
focusOnShow?: boolean
```

Whether the window automatically gains focus when [showWindow()]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_ is called. The default value is **true**. This parameter does not take effect for the main window, modal window, and dialog boxes.

**Type:** boolean

**Since:** 20

**ArkTS mode:** ArkTS-Dyn since version 20; ArkTS-Sta since version 23.

**Atomic service API:** This API can be used in atomic services since API version 20.
