## clearResourceCache

```TypeScript
clearResourceCache(): void
```

Clear the cache generated by using \$r/\$rawfile to retrieve resources. This cache is used to accelerate the process of repeatedly loading resources. Clearing this cache may slow down the loading speed of resources during page overload.

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Model restriction:** This API can be used only in the stage model.
