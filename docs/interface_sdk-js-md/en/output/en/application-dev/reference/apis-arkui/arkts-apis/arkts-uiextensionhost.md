# @ohos.uiExtensionHost

Intended only for the **UIExtensionComponent** that has process isolation requirements, the **uiExtensionHost** module provides APIs for obtaining the host application window information and information about the component itself. > **NOTE** > > No new function will be added to this module. Related functions will be provided in the > [uiExtension]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_ interface. > > The APIs provided by this module are system APIs.

**Since:** 11

**ArkTS mode:** ArkTS-Dyn since version 11; ArkTS-Sta since version 23.
