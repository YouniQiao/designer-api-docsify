# PubKey

Provides APIs for public key operations. **PubKey** is a child class of [Key]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_. It needs to be passed in during asymmetric encryption, signature verification, and key agreement. \_\_\_HTML\_TAG\_DESC\_USD\_3\_\_\_The public key can be generated by using the asymmetric key generator [AsyKeyGenerator]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_ or [AsyKeyGeneratorBySpec]\_\_\_JSDOC\_LINK\_DESC\_USD\_2\_\_\_.

**Inheritance/Implementation:** PubKey extends [Key](arkts-cryptoarchitecture-cryptoframework-key-i.md)

**Since:** 9

**ArkTS mode:** ArkTS-Dyn since version 9; ArkTS-Sta since version 23.
