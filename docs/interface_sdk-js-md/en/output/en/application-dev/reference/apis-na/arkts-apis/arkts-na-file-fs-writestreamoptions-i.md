# WriteStreamOptions

Defines the options used in createWriteStream().

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

## mode

```TypeScript
mode?: int
```

Option for creating the writeable stream.

**Type:** int

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

<!--Device-WriteStreamOptions-mode?: int--><!--Device-WriteStreamOptions-mode?: int-End-->

**System capability:** SystemCapability.FileManagement.File.FileIO

## start

```TypeScript
start?: long
```

Start position to write the data, in bytes. This parameter is optional. By default, data is written from the beginning of the file.

**Type:** long

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.
