# onDeviceConfigChange (System API)

## onDeviceConfigChange

```TypeScript
function onDeviceConfigChange(callback: Callback<int>): void
```

Subscribe Wi-Fi device config change events.

**Since:** 23

**ArkTS mode:** ArkTS-Sta only, since version 23.

**Required permissions:** ohos.permission.GET_WIFI_INFO

**System API:** This is a system API.

**Parameters:**

| Name | Type | Mandatory | Description |
| --- | --- | --- | --- |
| callback | \_\_\_MD\_LINK\_USD\_0\_\_\_&lt;int&gt; | Yes | the callback of on,0: config is added, 1: config is changed, 2: config is removed. |
