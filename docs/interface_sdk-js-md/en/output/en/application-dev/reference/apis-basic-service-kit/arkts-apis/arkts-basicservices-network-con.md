# Constants

## DATA_ROAMING_STATUS

```TypeScript
const DATA_ROAMING_STATUS: string
```

Specifies whether data roaming is enabled. \_\_\_HTML\_TAG\_DESC\_USD\_0\_\_\_If the value is {@code true}, data roaming is enabled. If the value is {@code false}, data roaming is disabled.

**Since:** 7

**ArkTS mode:** ArkTS-Dyn since version 7; ArkTS-Sta since version 23.

**Deprecated since:** 21

## HTTP_PROXY_CFG

```TypeScript
const HTTP_PROXY_CFG: string
```

Indicates the host name and port number of the global HTTP proxy. The host name and port number are separated by a colon (:).

**Since:** 7

**ArkTS mode:** ArkTS-Dyn since version 7; ArkTS-Sta since version 23.

**Deprecated since:** 21
