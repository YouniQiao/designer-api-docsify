# EffectId

Enumerates the preset vibration effect IDs. This parameter is needed when you call [vibrator.startVibration9+]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_ or [vibrator.stopVibration9+]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_ to deliver the vibration effect specified by [VibratePreset]\_\_\_JSDOC\_LINK\_DESC\_USD\_2\_\_\_. This parameter supports a variety of values, such as **haptic.clock.timer**. [HapticFeedback\_\_\_HTML\_TAG\_DESC\_USD\_5\_\_\_12+\_\_\_HTML\_TAG\_DESC\_USD\_6\_\_\_]\_\_\_JSDOC\_LINK\_DESC\_USD\_3\_\_\_ provides several frequently used **EffectId** values. > **NOTE** > > Preset effects vary according to devices. You are advised to call > [vibrator.isSupportEffect]\_\_\_JSDOC\_LINK\_DESC\_USD\_4\_\_\_\_\_\_HTML\_TAG\_DESC\_USD\_7\_\_\_10+\_\_\_HTML\_TAG\_DESC\_USD\_8\_\_\_ to check whether the > device supports the preset effect before use.

**Since:** 8
