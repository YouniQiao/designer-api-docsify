# TemplateId

Defines the **TemplateId** struct. **TemplateId** is generated by [**addTemplate**]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_ to identify a template.

**Since:** 10

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.

## bundleNameOfOwner

```TypeScript
bundleNameOfOwner: string
```

Bundle name of the template owner. The value must be the same as the **bundleName** in [**addTemplate**]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_.

**Type:** string

**Since:** 10

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.

## subscriberId

```TypeScript
subscriberId: string
```

ID of the subscriber who handles the callback. The value must the same as the **subscriberId** in [**addTemplate**]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_. The ID of each subscriber must be unique.

**Type:** string

**Since:** 10

**ArkTS mode:** ArkTS-Dyn since version 10; ArkTS-Sta since version 23.

**Model restriction:** This API can be used only in the stage model.
