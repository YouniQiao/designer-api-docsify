# TypeCode

Since API version 12, [writeArrayBuffer]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_ and [readArrayBuffer]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_ are added to pass ArrayBuffer data. The specific TypedArray type is determined by the **TypeCode** defined as follows:

**Since:** 12

**ArkTS mode:** ArkTS-Dyn since version 12; ArkTS-Sta since version 23.

**System capability:** SystemCapability.Communication.IPC.Core
