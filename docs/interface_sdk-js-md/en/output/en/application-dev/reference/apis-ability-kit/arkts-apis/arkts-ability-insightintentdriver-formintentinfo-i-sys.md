Describes the parameters supported by the \_\_\_MD\_LINK\_DESC\_USD\_0\_\_\_ decorator, such as the widget name. It also describes the widget information bound to the \_\_\_MD\_LINK\_DESC\_USD\_1\_\_\_.

**Since:** 20

**ArkTS mode:** ArkTS-Dyn since version 20; ArkTS-Sta since version 23.
