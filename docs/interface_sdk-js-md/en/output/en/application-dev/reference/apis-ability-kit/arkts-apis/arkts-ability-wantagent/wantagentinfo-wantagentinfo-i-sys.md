# WantAgentInfo

Defines the information required for triggering a WantAgent object. The information can be used as an input parameter in \_\_\_MD\_LINK\_DESC\_USD\_0\_\_\_ to obtain a specified WantAgent object.

**Since:** 7

**ArkTS mode:** ArkTS-Dyn since version 7; ArkTS-Sta since version 23.

## userId

```TypeScript
userId?: int
```

User ID. The value must be greater than or equal to 0. The default value is the user ID of the caller. This API can be used only in the stage model.

**Type:** int

**Since:** 23

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 23.

**Model restriction:** This API can be used only in the stage model.
