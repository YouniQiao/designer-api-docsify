# ExecuteModeForConfiguration (System API)

Enumerates the execution modes supported by an \_\_\_MD\_LINK\_DESC\_USD\_0\_\_\_. For example, if **executeMode** in the \_\_\_MD\_LINK\_DESC\_USD\_1\_\_\_ is set to **foreground**, the intent bound to the UIAbility can run in the foreground.

**Since:** 23

**ArkTS mode:** Both ArkTS-Dyn and ArkTS-Sta, since version 23.
